# 一、两个决定定价空间的数字

## 1.1 ⚠️ 真实费率是 **4.9% + $0.50**（不是 3.9%）

**★ 修正**：Waffo Pancake 有**两笔费** —— 交易费 **3.9% + $0.50**，
**外加提现费 1%（最低 $10）**。我此前只算了前者。

```
提现   $50   → max(1%×50, $10) = $10   →  占 20% ⚠️ 必须攒到 $1000+ 再提
```

**含提现费的**真实成本**：

| 定价 | 交易费 | 提现费(1%) | **真实成本** | 真实费率 | 旧表(仅交易费) |
|---|---|---|---|---|---|
| $0.99 | $0.54 | — | — | **~55%** ⚠️ | 54.5% |
| $4.99 | $0.69 | $0.04 | $0.73 | **14.7%** | 13.9% |
| $9.99 | $0.89 | $0.09 | $0.98 | **9.8%** | 8.9% |
| $19.99 | $1.28 | $0.19 | $1.47 | **7.4%** | 6.4% |
| **$29.99** | $1.67 | $0.28 | **$1.95** | **6.5%** | 5.6% |
| $39.99 | $2.06 | $0.38 | $2.44 | 6.1% | 5.2% |
| **$49（年订阅）** | $2.41 | $0.47 | **$2.88** | **5.9%** | 4.9% |
| $59.99 | $2.84 | $0.57 | $3.41 | 5.7% | 4.7% |

**结论（比旧版更强）**：不做 $5 以下；**$29.99 是费率拐点**；**年付最优**；
**提现必须攒到 $1000 以上**。

## 1.2 AI 边际成本 ≈ **$0.0016/次**（可忽略）

实测一次真实调用：`total_tokens: 6124`（输入 5041，含缓存命中 4864 ＋ 输出 1083）

→ 约 **¥0.012 ≈ $0.0016**，占 $29.99 报告收入的 **0.005%**。

> **★ 含义**：**定价的约束是「感知价值」与「付费意愿」，不是成本。**
> **免费层可以给得非常大方。**

**连 $39.99 的定价者都觉得"卖便宜了"。而原方案是它的四分之一。**

# 三、免费 / 付费的边界

## 3.1 ★ 划分原则：**免费给「判断」，付费给「行动」**

```
免费：告诉你【是什么】    —— 命局结构与总体倾向
付费：告诉你【怎么办】    —— 每十年怎么走、每年宜忌、具体建议
```

**为什么用这条线**：被"你财运滞"说服的人**不会付费**；
只有想要"**那我这十年到底该干什么**"的人才会付费。

## 3.2 免费层（**已拍板：不收缩**）

| 免费内容 | 理由 |
|---|---|
| **完整排盘** —— 四柱、十神、旺衰、格局、大运/流年/流月**干支** | 零成本；行业惯例，收费立刻劝退 |
| **总体判断** —— 旺衰、格局、喜用忌神、五行分布 | "是什么"，不是"怎么办" |
| **★ 结构病** —— "比劫林立、财星深藏"这类**方法论展示** | **我们最差异化的一块**，零成本 |
| **★ 命例库检索** —— 古籍命例 ＋ **逐条出处** | **别人没有的资产**，免费＝最强信任背书 |
| **一个模块的 AI 深度解读**（建议地理或紫微） | **试吃** —— 让用户看到 AI 质量 |
| **★ 通用日签**（每日，可分享） | **获客** —— 见 §四-4.4 |
| 全部知识文章 | SEO 入口 |

> **为什么坚持不缩**：
> **免费层越可信，付费层越能收高价。**
> 我们免费送的（结构病、命例库）传达的是"**这家在做学问，不是做话术**" ——
> **而这恰好是支撑 $29.99 的理由。**
> **FateTell 的免费层比我们小，但不建议跟着缩 —— 我们是挑战者，需要用"给得多"建立信任。**

## 3.3 付费层

|---|---|---|
| **命书**（核心深度报告） | 单次 | 十年大运逐步 ＋ 流年流月 ＋ AI 十段 —— "怎么办" |

| **合婚报告** | 单次 | 双人 ＋ 情感价值最高 |
| **紫微深度** | 单次 | 独立体系（**FateTell 没有**） |
| **地理·财富之城** | 单次 | **我们独有** |
| **个性化日运 ＋ 流月更新** | **订阅** | **高频钩子**（见 §四） |
| 追问额度包 | 额度（V2） | 学 FateTell 的对话包 |

# 四、★ 订阅结构：从「全站解锁」改为「高频额度」

## 4.1 v1 原方案的自相矛盾（**已修正，此处留档**）

**v1 是**：单次 **$9.9** ＋ 年订阅 **$59** = **全站解锁**。

```
用户算一下：买 6 份单次才 $59.4，和订阅一样
而"全站解锁"还包含日运与流月
→ 订阅侵蚀了单次报告的销售
```

**根因**：**"订阅解锁一切"这个结构本身有问题** ——
它让订阅与报告变成**同一类东西的两个价格**，而不是两类东西。
**v2/v3 已按 §4.2 拆开。**

## 4.2 新结构（学 FateTell）

```
报告（$19.99–$29.99）  → 单独买，高单价，一次性
订阅（$49/年）          → 只卖【高频】：个性化日运（每日）＋ 流月更新
                          【不含报告】
```

**两条线卖两种不同的东西**：**报告卖深度（一次性），订阅卖持续（每日）。互不侵蚀。**

## 4.3 但订阅要立得住，必须先有高频钩子

**这是我们原本缺的。** 现在补上：

| 钩子 | 状态 |
|---|---|
| **个性化日运**（每日） | **新增** —— 见 `docs/日运日签-设计.md` |
| **流月更新**（每月） | 数据已有（`buildLuckLiuYue`） |
| 追问/对话（V2） | 无 —— **FateTell 的核心粘性，建议排入 V2** |

## 4.4 日签为什么建议免费

> **日签的传播价值远大于它的付费价值。**
> 它天生适合分享（图片、短句）—— **免费才能发挥获客作用；锁在订阅里等于放弃拉新。**
>
> **而订阅需要"更个人化"的东西**：通用日签和天气 App 一样谁都能做，
> **"结合你的盘"才是订阅理由。**

详见 [`docs/日运日签-设计.md`](日运日签-设计.md)。

- **年订阅 $59 → $49** —— 见 §5.2 的取舍论证

## 5.2 定价原则（三条）

```
报告类：比竞品低 25%（挑战者位置）        —— $29.99 vs $39.99
订阅类：比竞品低约 18%                    —— $49 vs $59.99
订阅内部：年付价 ≈ 5 个月月付价（省 59%）  —— 强推年付
```

**为什么订阅比竞品低而不是平价**：

| 理由 | 说明 |
|---|---|
| **我们是挑战者** | 它有品牌、App、一年多运营；同样的东西我们收得更贵没有说服力 |
| **它的钩子更强** | 它有"对话 20 次/日"；我们的钩子是日运＋流月（追问在 V2）<br>**钩子弱一档，价格就该低一档** |
| **★ 换订阅占比** | **FateTell 的收入 70% 来自订阅**（见 §2.3）。<br>订阅 LTV 更高、现金流更好 —— **用价格换订阅占比是划算的** |

**而"年付 ≈ 5 个月"是我们主动的选择** —— 见 §1.1，年付费率 4.9% vs 月付 8.9%，
**现金前置 + 费率减半，值得让掉 59%。**

## 5.3 ★ 修正带来的净收入差

| | 原方案 | **新方案** | 倍数 |
|---|---|---|---|
| 命书定价 | $9.9 | **$29.99** | — |
| 手续费 | $0.89 (8.9%) | $1.67 (5.6%) | — |
| **实收** | **$9.10** | **$28.32** | **3.1×** |

**同样卖一份，净收入 3.1 倍，费率还降了三分之一。**

## 5.4 不做的事：点数 / Credits

**理由**：点数制的本质是"多次小额"，而 **MoR 的 $0.50 固定费恰好惩罚多次小额**。

| 想要的效果 | 正确做法 | 错误做法 |
|---|---|---|
| 降低门槛 | 便宜的**单模块报告**（$19.99） | 点数 |
| 提高客单 | **打包**（$59.99） | 点数 |
| 做复购 | **年订阅** | 点数 |

> **例外**：FateTell 的「$4.99/15次对话」不是点数制，而是**额度包** ——
> 它是**一次交易、多次使用**（一笔手续费），可以学。

## 6.2 ★ 需要改的七处（按依赖顺序）

### ⓪ ⚠️ 先说一个必须先补的洞：`/api/unlock` 现在是「登录即解锁」

```
1. 校验 token（登录）                        ✓
2. 检查会员状态                              ✓
3. 跑 generateAnalysis + generateAIAnalysis
4. ★ 直接返回完整付费报告（analysis.paid）   ← 【没有任何支付校验】
5. 之后才插一条 MOCK 流水（amount 19.9, transaction_id 'MOCK_...'）
```

**→ 任何【登录】用户调用 `/api/unlock`，都能拿到完整付费报告。
付费墙的实际强度 = "是否登录"，不是"是否付费"。**

**修法**：

```
1. 校验 token
2. ★ 取 entitlements（会员 或 已购该 SKU）
3. ★ 无权限 → 402/403，【不计算、不返回】付费内容
4. 有权限才计算并返回
5. 流水由【支付回调】写，不在这里写
```

# 七、合规与伦理红线

行业反面教材：测测被 **3·15 系列报道**点名，
投诉集中在「**诱导高额消费**」「**半年花 13 万**」，报道批评其「**隐秘的成瘾机制**」。

**本方案天然站在它的对面 —— 这一条要固化成产品约束**：

| 红线 | 具体含义 |
|---|---|
| **不做恐吓式升级** | 不卖"化解"、不卖"补运"、不做"限期不处理会有灾" |
| **客单封顶** | 单次 $19.99–$59.99，**没有可无限叠加的计时/连麦计费** |
| **明码标价** | 价目在 `/pricing` 一目了然；**不在报告里插入诱导性升级** |
| **不给绝对断言** | 已在 AI 层落地（禁「大吉/大凶」）—— **付费内容同样受约束** |
| **不做成瘾式召回** | 不做"你已 N 天没查、运势下滑"这类推送 |

> **「低客单、说清楚、不吓人」既是伦理，也是最安全的商业位置。**

## 8.1 ⚠️ 追问（V2）需要一份**单独的设计**，原因如下

追问与日签的**性质完全不同**，不能照搬：

| | 日签（§四） | **追问（V2）** |
|---|---|---|
| 输出 | **静态文案**（180–300 条） | **实时 AI 生成** |
| 可否逐条审核 | ✅ **可以** | ❌ **不可以** |
| 风险 | 低 | **高** |

**追问的风险在于用户会问直接决策类问题**：

```
"我该不该辞职？"      → AI 不能答"该"或"不该"
"我们该不该离婚？"     → 同上
"我还能活多久？"      → 必须拒答
"该买这只股票吗？"     → 涉及投资建议，必须拒答
```

**因此追问需要一套独立设计**，至少包含：

1. **硬拒答清单**（医疗 / 法律 / 投资 / 生死 / 重大人生决策的"该不该"）
2. **改写法**：把"该不该"**重构**为"命局倾向 ＋ 你自己权衡"——**给依据，不给判决**
3. **运行时合规检查**：复用 `ai-check.ts` 的 `findForbidden` ＋ `withComplianceRetry`
4. **每条回答带免责**（比报告更强，因为问答更直接）
5. **额度与费率**：$4.99/15 次；订阅内含额度

> **结论**：追问应在 V2 单独立项设计，**不要与日运/日签混在一份任务书里**。

# 十、一句话

> **v1 的价格是"自认不如"的价格。** 直接竞品命书卖 $39.99，
> 而它的创始人还说"**还有人觉得我们卖便宜了**"。
>
> **v2 的两条定价原则**：
> **报告比竞品低 25%（挑战者位置，$29.99），订阅比竞品低 18%（$49/年）。**
>
> **而比价格更重要的结构修正**：
> **报告卖深度（一次性），订阅卖持续（每日日运 ＋ 流月）—— 两条线互不侵蚀。**
> 这正是 FateTell 的核心设计，也是我们原方案"全站解锁"最大的问题。
>
> **免费层坚持不缩**：**免费层越可信，付费层越能收高价。**
> 我们免费送的（结构病、带出处的古籍命例库）传达的是"这家在做学问" ——
> **而这恰好是支撑 $29.99 的理由。**
>
> **而在收第一分钱之前，有一个洞必须先补**：
> **`/api/unlock` 现在是「登录即解锁」** —— 付费墙的实际强度是"是否登录"。
