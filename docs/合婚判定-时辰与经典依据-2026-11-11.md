# 合婚判定：时辰的作用与经典依据（2026-11-11）

本文件是**对外专业性的底稿**：回答「缺时辰能不能合婚」「哪些结论站得住」，供写文章、答用户质疑、评审产品口径时引用。
凡经典依据不足的，保留「依据不足」结论，不因表述好看而删改。

方法：按子平六书（《渊海子平》《三命通会》《子平真诠》《滴天髓》《穷通宝鉴》《千里命稿》）+ 古法（《五行精纪》《兰台妙选》）+ 病药（《神峰通考》）逐条核，不取网络通行说法。
底本行号指各书笔记所标原文位置。

## 一、A 组：仅需年、月、日（时柱不影响）

| # | 判断项 | 用柱 | 经典依据 | 备注 |
|---|---|---|---|---|
| A1 | 夫妻宫（日支）与对方日支的冲、合、害、刑 | 日柱 | 《三命通会》卷七·论六亲·妻宫断（底本 2340）；《千里命稿》·六亲篇·妻财（2631） | 日支即夫妻宫，二者关系只由两个日柱决定 |
| A2 | 双方日干五行生克 | 日柱 | 《滴天髓》·夫妻（415–416） | 日主对日主，不涉时柱 |
| A3 | 男命财星 / 女命官星**是否透于年、月、日干** | 年、月、日 | 《渊海子平》·六亲总篇（501–503）：「正财为妻」「妇人命取官星为夫星，七杀是偏夫」 | 只判「透与不透」，不判旺衰；落时者不可判 |
| A4 | 生肖（年支）冲合害刑 | 年柱 | 古法·民俗层（见 C1） | 可算，但**不作主断** |
| A5 | 年柱纳音生克 | 年柱 | 《五行精纪》《兰台妙选》 | 古法参断层（见 C2） |
| A6 | 日支藏干与对方日干的十神关系 | 日柱 | 《子平真诠》十神法 | 三柱内可判，属夫妻宫的补充说明 |

> 说明：A1–A3 是缺时辰时**唯三**可以正面下判断的项目；A4–A6 属辅助说明或古法参断。

## 二、B 组：必须完整四柱

| # | 判断项 | 为什么必须四柱 | 经典依据 |
|---|---|---|---|
| B1 | 五行强弱统计（旺衰） | 时支可通根、时干可透印比，足以翻转身强身弱；旺衰一错，取用全错 | 《滴天髓》·旺衰真机（须全局）；同书 247 行：「时柱为归宿」，用忌在时「吉凶绵延终身」 |
| B2 | 配偶星旺衰与落时 | 财/官落时，其旺衰死墓绝直接改判克妻克夫 | 《三命通会》妻宫断（2340）：「若在本命**时**财死墓绝败处，定主克陷，或一生鳏居」 |
| B3 | 时支与日支（夫妻宫）的冲合害刑 | 时支冲日支即冲妻宫 | 同上（2340）：「日带自刃，名曰日煞，或**时羊刃归日**，俱主克妻」 |
| B4 | 时柱十神（时上偏财、时上伤官等） | 时上财官是独立格局条件 | 《三命通会》杂格·时上财官（6571）；《子平真诠》时上格 |
| B5 | 子女宫相关 | 时柱即子女宫；婚姻与子女常同步判断 | 《五行精纪》L2813「**日犯克妻，时犯克子**」、L3466「时紧日慢」；《三命通会》675「日煞克妻，时煞克子」；同书 2345 子息 |
| B6 | 大运同步 | 大运干支排法本身不需时柱，但**大运喜忌须以完整旺衰为前提**，且起运岁数精度受时辰影响（差一时辰约 0.04 年）；前提不成立则结论不成立 | 《千里命稿》·三日折一岁（§1.4）；《子平真诠》取运六辨 |

> B6 的措辞要准确：不是「算不出来」，是**「前提不成立 + 精度不足」**，所以同样降级不输出。

## 三、C 组：依据不足或各家不一

| # | 说法 | 判定 | 依据 |
|---|---|---|---|
| C1 | 属相（生肖）合婚决定吉凶 | **依据不足，子平主干不取** | 《神峰通考》·男女合婚说（223–233）点名驳吕才「合婚上中下三婚」：「吕才说之谬，**不足信也明矣**」 |
| C2 | 年柱纳音合婚为主断 | **依据不足为主断**，只能参断 | 古法层「不得夺子平生克格局的主断地位」（本 skill §五.1） |
| C3 | 神煞合婚（孤鸾、红艳、阴阳差错） | 参断层，不主吉凶 | 《三命通会》孤鸾（747）、阴阳差错（1045）等；神煞四原则「不主吉凶，生克才主吉凶」 |
| C4 | 缺时辰「以午时权代」 | **无经典依据**；六书无「未知时辰代以午时」的正面条文 | 反证：《子平真诠》赵侍郎造「底本仅三柱」（218 行）——古人有三柱论命实例，但**注明不全**，未伪造时柱 |
| C5 | 缺时辰能否合婚 | **各家不一**：有三柱论日支与日主关系者，也有主张缺时不断婚者；无统一裁断 | 六书无专条，只能依「不全则声明不全」通例 |
| C6 | 合婚的「正理」 | 《神峰通考》只给了一条：男带比劫重者，配女带伤官食神重者 | 原文（234）：「但当看男命，带比肩劫财重者，必择妇命带伤官食神重者配之」——注意此条**需要十神强弱**，即需四柱 |

## 四、结论

1. **缺时辰可以给结论，但只有三条**：夫妻宫（日支）关系、双方日干生克、配偶星是否透干。
2. **不能用午时代入**。午时会进入五行统计、配偶星藏干、婚姻宫时支关系，产出看似完整、实则错误的结果——这不是「粗」，是「错」。
3. **不能给总分、类型定论、大运表**。总分与类型都建立在旺衰之上，缺柱时二者皆无依据。
4. 生肖、纳音、神煞可以出现，但必须标「古法参断」，且不得排在与夫妻宫同等位置。
5. 缺时的正确表述是「本次仅以年、月、日三柱论，不含时柱」，并列出不给的项，不是「大致看看」。

## 五、仓库引擎对照（核对，非修改）

`src/lib/hemun.ts` 九维实际用柱：

| 维度 | 用柱 | 缺时影响 | 与经典要求是否一致 |
|---|---|---|---|
| 生肖配对 | 年支 | 无 | 一致（年柱即可） |
| 年柱干支 / 纳音 | 年柱 | 无 | 一致 |
| 日柱夫妻宫 | 日支 | 无 | 一致 |
| 五行互补 | 四柱统计（L134） | **受影响** | 一致：确实需要四柱 |
| 配偶星 | 日主 + 四柱藏干（L292–310） | **受影响** | 一致 |
| 婚姻宫稳定度 | 日支 vs 年/月/时支（L371–372） | **受影响** | 一致 |
| 十神互见 | 四柱 | **受影响** | 一致 |
| 大运同步 | 起运（需时刻） | **受影响** | 一致（精度 + 前提） |
| 婚姻宫·合参（overall） | 综合 | **受影响** | 一致：故 overall 在缺时下不可输出 |

**核对结论**：引擎本身的用柱是正确的，问题只在**缺时若传 12:00 会静默产出错误结果**。因此产品侧必须在引擎层显式禁用，而不是靠传默认值。

## 六、可写进产品的措辞方向

**该说**

- 「你未填写出生时辰，本次仅以年、月、日三柱论合婚。」
- 「夫妻宫（日支）为 X，与对方日支 Y 成 Z。」
- 「本次不计算：五行互补、配偶星旺衰、婚姻宫稳定度、十神互见、大运同步、子女宫——这些需要完整四柱。」

**不该说**

- 「按午时推算」「默认午时」——编造。
- 「综合评分」「关系类型」——缺柱时等于伪造精度。
- 「大致/大概」——用模糊词掩盖缺失。
- 任何大运年份表、子女判断、时柱神煞。
