# 〇、名字要过的三道关（不是审美问题）

| # | 关卡 | 说明 |
|---|---|---|
| 1 | **域名可注册** | `.com` 优先 —— 审核与客户信任都看它 |
| 2 | **商标清白** | Waffo 审核项之一：「产品名不得侵犯既有商标」 |
| 3 | **支付审核看得懂** | 名字不能像是"占卜/玄学灰产"，否则受限类目审核更难过 |

**外加四条产品约束**：

```
① 英文用户能念、能拼（收据和口口相传都要靠它）
② 账单描述符友好（信用卡账单显示名，约 ≤22 字符）
③ 可扩展 —— 不能把产品框死在八字（我们还有紫微/合婚/地理）
④ 与定位契合 —— 「讲依据、不吓人」
```

# 二、★ 按你的用神/喜神/调候筛选（**引擎实测**）

## 2.2 ★ 三方交集是【木】

```
扶抑（身强喜泄耗）：  木 = 喜神        ✓
调候（甲庚，取甲）：  甲木 = 调候用神   ✓
```

**土、火亦吉**：土＝第一用神（七杀本身），火＝喜神（财，且财生杀）。
**忌：金、水。**

```
★ 品牌五行宜取【木（首选）／火／土】，避【金／水】
```

## 2.3 ⚠️ 这一条推翻了我上一条推荐里的关键点

`MingCharts` 的 "Ming" 可以对应很多汉字：**明、命、名、鸣、铭、冥…**
**名字合不合格，取决于我们把哪个字定为「品牌正字」。**

| 正字 | 五行 | 判定 |
|---|---|---|
| **「命」** | **归属不一**（有水、有火之说） | ❌ **不宜作依据**；且传统姓名学认为**「命」字太大，不宜入名号**（"命"是天的权柄）。**若按水论，正是你的忌神** |
| **「明」** | **火**（日+月，字义为光；**字义与部首两体系都指向火，共识度高**） | ✅ **火＝你的喜神** |

**→ 结论：`MingCharts` 读作「命盘」不合格；读作「明盘」合格。**

**而「明」的字义（光明、明白、明理）恰好就是产品定位**（讲依据、不吓人、明明白白）✓

## 2.4 ★ 一个必须说清的方法论边界

```
① 五行附着在【汉字】上。纯英文品牌（英文用户只看到字母）无从谈五行。
② 但我们的界面是中文 → 品牌会以汉字呈现 → 五行成立 ✓
   所以：若要在意五行，品牌就必须有一个明确的【正字】（哪怕对外是拼音）。
③ 五行的严格程度：人名 > 商号。品牌五行是【加分项，不是决定项】。
   品牌首先要商业上成立（域名/好念/可扩展/无商标），五行在其上做优化。
④ 本方案只用了【子平】的用神/喜神/调候（你点名的三项）。
   另有【五格剖象】(笔画数理) 一派，与子平无关 —— 如要一并看，需另说。
```

# 五、⚠️ 但比英文名更重要的一个问题：**要不要中文名？**

**现状**：**UI 全中文，没有 i18n**。所以**短期真实用户是海外华人**。

| 方案 | 适合 | 代价 |
|---|---|---|
| **A. 纯英文品牌**（如 `MingCharts`） | 长期北美市场 | 中文用户少一层亲近感；但 romanized 名字中文用户也看得懂 |
| **B. 中文品牌 + 拼音域名** | 短期海外华人 | 英文用户念不出中文名，长期要再起一个英文名 |
| **C. 双名**（中文名 ＋ 英文名） | 两边都要 | 需要两个名字都注册、都对得上 |

**我倾向 A（纯 romanized）**，理由：

```
① 我们短期用户虽以华人为主，但 romanized 名字（MingCharts）中文用户同样读得懂
② 长期做北美时不必改名 —— 改名的代价极高（域名/商标/App/收据全要重来）
③ 支付审核与 App Store 都看英文名
```

**中文品牌名（若你要 B/C）我的候选**：

| 中文名 | 出处 | 含义 |
|---|---|---|
| **「明理」** | — | **谐音「命理」，字面意思是"讲道理"** —— 名字本身就在说我们的主张 |
| **「知命」** | 《论语》"五十而知天命" | 了解自己，非宿命论；有经典根基，不吓人 |
| **「命典」** | — | 典籍/字典 —— 契合命例库与依据分级 |
| **「三命」** | 《三命通会》 | **我们命例库的出处**，学术味最重 |

> **我个人最喜欢「明理」** —— 它一个字不用改就把"命理"和"讲依据"同时说了。
> 但 `mingli.com` 已被注册，需要配 `.app` 或加后缀（如 `mingli.app`）。
