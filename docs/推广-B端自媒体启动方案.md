> 成功判据（4 周）：**有命理师主动私信问「你用的是什么工具」≥ 1 个**

# 二、内容武器：把 53 篇神煞做成「速查卡」

## 为什么是神煞

```
✓ 命理师每天要用（不是知识科普，是工作工具）
✓ 有口诀、有出典、可核对 —— 一眼看出专业度
✓ 天然适合做图（口诀 + 查法 + 一句立场 = 一张卡）
✓ 别人抄不走：53 篇全覆盖 + 每条标典籍
```

## 已出的样卡

`public/shensha-tongzi.png`（1080×1350，可直接发 FB/IG/LINE）

结构固定为四块：

```
① 神煞名 + 一句钩子
② 民间口诀（原文）
③ 怎麼查（分季节/冲合的具体干支）
④ ★ 這一句最要緊（立场 + 出典）
```

## 先做的 5 张（按「命理师最需要、最容易吵起来」排序）

| # | 神煞 | 为什么是它 |
|---|---|---|
| 01 | **童子煞** | 流傳最廣、最容易被拿來嚇人。我们明说「子平正典不取此说」——**立场鲜明，会被有良知的同行转发** ✅ 已出 |
| 02 | **天乙貴人** | 最常被問的貴人星，人人想查 |
| 03 | **空亡** | 最常被誤解（很多人以為空亡就凶） |
| 04 | **羊刃** | 爭議最大，常被亂用（羊刃不是必凶） |
| 05 | **六秀日** | GSC 已有真實搜索（0 點擊/3 曝光），說明需求在 |

## 文案模板（每張卡配一段，发帖时贴）

```
【神煞速查 01】童子煞

口訣：春秋寅子貴，冬夏卯未辰；金木馬卯合，水火雞犬多，土命逢辰巳。

★ 這一條最要緊：
子平正典（《淵海子平》《三命通會》體系）並不以童子煞為判據。
它是民俗傳說，不是命理斷語 —— 健康看五行旺衰，婚姻看夫妻宮與配偶星。

（五十三個神煞查法，逐條標註典籍出處）
```

**注意：帖子里不放链接。** 品牌只在图片页脚和主页简介里。

# 三、平台与入场方式

## 优先级

| 平台 | 为什么 | 入场方式 |
|---|---|---|
| **① Facebook 社团** | 台湾/香港/马来西亚华人命理师主要在 FB 社团活动；35+ 客群渗透率最高 | 搜索并加入 3–5 个「八字」「紫微」「命理」研究社 |
| **② YouTube 评论区** | 命理师的视频下聚集着同行与爱好者 | 在讲神煞/格局的视频下留**补充出典**的评论 |
| **③ destiny.to / 88say 论坛** | 台湾命理师接单与讨论的地方 | 注册后回答提问 |
| **④ LINE 社群** | 台湾命理圈常在此交流 | 通过社团里的人拉入 |
| ⑤ 小红书 | 马来西亚/新加坡中文圈有量 | 只做品牌，不带链接（限流风险） |
| ⑥ 知乎/贴吧 | 大陆 | **低优先**：大陆收不了国际卡，来了也付不了款 |

## 诚实说明

**我打不开 Facebook 社团内部**（需要登录），所以给不了"已验证的社团名单"。
给你的是**搜索关键词 + 验证方法**：

```
搜索词（FB）：
  台湾  八字 研究社 / 紫微斗數 交流 / 命理 討論 / 子平八字
  香港  八字 命理 / 玄學 交流 / 命理 討論區
  新马  八字 命理 交流 / 紫微斗數 馬來西亞

验证标准（加入前看三件事）：
  ① 成员数 ≥ 2000
  ② 近 3 天有新帖（死社团没用）
  ③ 有没有「禁止广告」条款 —— 有也没关系，我们本来就不发广告
```

# 四、每周动作（每天 15 分钟，可长期坚持）

## 每天：回答 1 个问题（不是发帖）

在社团/论坛里找**有人问神煞、格局、查法**的帖子，用我们的内容回答：

```
① 先给答案（口诀/查法，准确）
② 再给出典（哪个古籍、哪一版）
③ 一句立场（例：童子煞是民俗，正典不取）
④ 不贴链接、不提产品
```

**为什么这样有效**：命理师最缺的不是知识，是**能当场引经据典的底气**。
你给了这个，他会记住你，然后点你主页。

## 每周：发 1 张速查卡

```
FB 粉专 / 个人页 / IG 同步发
标题用【神煞速查 0X】+ 神煞名
正文用上面的模板
不放链接
```

## 主页简介（唯一的自我说明）

```
做命理報告引擎（mingcharts.com）。
五十三個神煞查法、格局十神，逐條標註典籍出處。
```

**这三行是整个 B 端策略里最重要的地方**——所有内容都不带链接，链接靠这里承接。

# 五、成功判据（4 周后看）

| 指标 | 合格线 | 说明 |
|---|---|---|
| 有人主动私信问「你用的是什么工具」 | **≥ 1 个** | ★ 唯一真正的成功判据 |
| 回答被点赞/被回复 | ≥ 10 次 | 证明专业度被认可 |
| 主页/简介被点击 | ≥ 30 次 | 有承接 |
| 新伙伴线索 | ≥ 1 个 | 从这些互动里发展出来的 |

**没到合格线怎么办**：说明「以专业身份出现在社团」这条路不通，
换赛道——去 YouTube 做 3 分钟的神煞讲解（视频比文字更容易被转发）。

# 六、红线（违反一次就前功尽弃）

```
✗ 社团里发链接/发广告（多数社团直接踢，且会被同行记住）
✗ 在别人帖子下面推销（最招恨的一种）
✗ 用小号/多号刷（一旦被发现，专业形象全无）
✗ 贬低靠童子煞做法的同行（我们只讲立场，不点名、不批评个人）
✗ 一次把 53 张卡全发出去（会被当营销号；一周一张，慢慢累积）
✓ 被质疑「你是不是来卖东西的」→ 直说：是啊，我做工具，但这条回答不需要你买
```
