## 二、我方操作步骤（伙伴注册之后）

### 1. 给他开通试用额度

```powershell
npm run partners:credits -- --grant <他的邮箱> --units 2 --note "首单试用 2 份"
```

- 额度按 `partner_credits` 账本记，`--units 2` 就是 2 份
- **只有账本里有记录的账号才能进 `/partner`** —— grant 之后他刷新即可看到余额

### 2. 确认他能进工作台

让他打开 https://www.mingcharts.com/partner
- 能进 → 顶部显示「剩余 2 份」
- 提示「该页面仅对合作命理师开放」→ 说明 grant 没生效或邮箱不一致，查 `--list`

### 3. 查余额与流水

```powershell
npm run partners:credits -- --list                      # 所有伙伴余额
npm run partners:credits -- --balance <邮箱>             # 单个 + 流水
```

### 4. 他买了第一笔之后

```powershell
npm run partners:credits -- --list
```

付款由 Waffo webhook **自动入账**，不需要我们动手；扣减也是系统自动的（每生成一份扣 1）。

## 三、必须提前说清的三件事（避免后面扯皮）

### ① 报告目前只有简体

V2 只做了 **简体报告 + 繁体页面**。如果他问「能出繁体吗」：

```
目前报告正文是简体，繁体版在做。
```

**不要承诺时间**。

### ② 报告开头一定有来源披露

每份报告开头都会写：

```
本报告由明理引擎依据命盘生成，逐条注明所引经典；解读仅供传统文化参考。
```

这句**不可移除**，也是我方的伦理红线。对伙伴的说法：

```
照实说，而且照实说对你更有利：「这份报告是我用工具按你的盘生成的，
我把不同意的都改过，剩下的我跟你逐条讲。」
```

### ③ 我们不碰他的客户

报告页面上**没有任何指向我方消费端的入口**（这是我对伙伴的书面承诺，已写进 `/partners`）：

```
放什么：他的品牌 + 联系方式 · 打印/存 PDF · 转发这份报告 · 来源披露
不放什么：免费排盘、定价、注册引导
```

## 四、常见问题（他可能问）

| 他问 | 怎么答 |
|---|---|
| 一份多少钱 | 10 份档 $15/份（$150）、50 份 $12、200 份 $9；一年内用完 |
| 额度会过期吗 | 24 个月内有效 |
| 报告能改吗 | 正文不能改（合规过滤在里面）；品牌名和联系方式可以填 |
| 客户退款怎么办 | 钱在他那，退款由他处理；我们只负责技术问题补发 |
| 能不能只买 1 份 | 不单卖，最低 10 份档（可以先要 2 份免费试用） |
| 付款方式 | 国际信用卡（Waffo 收款）；大陆客户暂时付不了 |
