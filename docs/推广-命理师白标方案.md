# 命理师白标 /partners 方案（分销线）

> **性质**：增长线规格（可执行、可验收），不是代码实现
> **日期**：2026-10-22
> **前置**：[`定价方案.md`](定价方案.md) · [`收款接入方案.md`](收款接入方案.md) · [`推广-繁体化改造清单.md`](推广-繁体化改造清单.md)
> **一句话**：把命理师变成我们的**批发采购方**，而不是我们的「渠道」——
> 他们收款、他们面对客户，我们只交付数字内容。

---

# 一、为什么这条线排在 SEO 前面（三条理由，都是硬的）

```
★ 1. 它把我们最大的约束【反转成优势】
     我们只收国际卡（支付宝类目禁入，已定案）→ 大陆/部分港台客户付不了。
     命理师本来就有自己的收款方式（台湾转账、马来西亚 DuitNow、香港 FPS、
     甚至面交现金）。他们收款，我们收他们的钱 —— 我们的收款瓶颈直接消失。

★ 2. CAC ≈ 0，且不依赖收录
     SEO 要等 Google 收录、排名、点击；白标是【逐个谈出来的】，
     第一个伙伴当月就能产生收入。2000 万条命理长尾里我们不占优势，
     但「一个台中的紫微老师」这种客户，一个人就能谈下来。

★ 3. 可复购、可预测
     个人用户买一次命书就结束了（一次性 $29.99）；
     命理师每月固定服务 20–50 个客户 → 每月固定消耗 20–50 份。
     这是订阅式的 B2B 现金流，不是一个一个卖。
```

**代价要说清**：这条线**赚的是辛苦钱**——一个个 DM、一个个教、一个个手把手跑第一单。它不是「睡后收入」。但它是唯一能在 SEO 起量之前给出正现金流的路。

# 二、客户是谁（不要泛泛说"命理师"）

## 2-1. 三类可触达，按优先级

| 优先级 | 群体 | 特征 | 他们缺什么 |
|---|---|---|---|
| **P0** | 台/港 **个人命理师**（IG/Threads 接单） | 一人工作室，靠私域与口碑；收费 NT$1,200–3,000 / 次 | **交付慢**。手写批命 3–5 小时/份，接单量被自己的时间锁死 |
| **P0** | **马来西亚/新加坡** 华人命理师 | 常兼看风水/择日；简体繁体混用；付费意愿高 | 缺**体系化的文字报告**，只能口头或用旧模板 |
| **P1** | 海外华人 **YouTube / 播客** 命理博主 | 有流量、有信任，但**没有后端交付** | 想把流量变成收入，缺交付物与收银台 |
| **P2** | 大陆玄学博主 | 流量大 | ★ **暂不接**：付款需国际卡、内容合规风险最高（见 §七） |

## 2-2. 他们的真实痛点（话术要打这里，不是打"AI 好厉害"）

```
① 「批一份命要 3 小时，我一天最多 3 份」        → 交付速度
② 「客户付了钱，我等三天才给报告」             → 交付时延
③ 「我不会写长文，讲得出但写不漂亮」           → 交付质量
④ 「紫微我也看，但合婚要两个人，太费时间」      → 品类覆盖
⑤ 「想涨价，但怕客户觉得不值」                 → 提价理由
```

**我们的价值主张一句话**：
> 你花 10 分钟排盘与校对，我们出万字命书；你按自己的价格卖，差价归你。

# 三、卖什么：三种交付形态，v1 只做第一种

| 形态 | 是什么 | 工作量 | v1 |
|---|---|---|---|
| **A. 报告分享链接 + 浏览器打印** | 生成一份**可分享、带伙伴品牌**的报告页；伙伴用浏览器「打印为 PDF」发给客户 | 小（复用现有报告页 + `@media print` 样式 + 分享令牌） | ✅ **做** |
| B. 服务端 PDF（带 logo/页眉页脚/水印） | 一键下载品牌化 PDF | 中（需 PDF 渲染字体与模板，中文排版是坑） | 第 2 月 |
| C. 白标子域 / 独立站 | `老师名.mingcharts.com` | 大 | 不做（至少 100 个活跃伙伴前没意义） |

**为什么 v1 选 A**：`src/app/reports/[id]` 已有完整报告页，缺的只是
①一个**免登录的分享令牌**（现在必须登录才能看）②打印样式 ③伙伴品牌位。
三者都不引入新依赖、不碰 AI 引擎。**别为了"看起来高级"先做 PDF**——pdf 中文排版会吃掉两周。

## 3-1. 报告里伙伴能改什么、不能改什么

```
可以改：页眉品牌名、logo、联系方式、报价单页、报告封面语（选填）
不可以改：正文（一字不改）、免责声明（必须保留）、页脚「由 明理 mingcharts.com 引擎生成」（必须保留）
```

★ 页脚那一行是**尾款条款**：伙伴可以宣称"我团队出品"，但不能宣称"我自研引擎"。
它同时是我们唯一的品牌回流入口（客户点进去 → 我们自己也能被搜到）。

# 四、定价与分成：批发额度制（不是佣金分账）

## 4-1. ★ 为什么不做「我们收钱、给伙伴返佣」

```
✗ 我们收了客户的钱再分给伙伴 → 我们变成付款方：
   · 没有出款能力（自然人对自然人跨境付款，银行与税务都过不去）
   · MoR（Waffo）按我们自己的商品结算，分账不在其能力范围
   · 每一笔都要开发票/扣税/做账 → 会计成本 > 单笔毛利
✓ 伙伴先买额度、我们后交付 → 我们是【收到钱的一方】，永远不做出款方
```

## 4-2. 批发价目表（USD；伙伴自己定价、自己收款、差价归他）

| SKU | 我们的零售价 | 10 份档 | 50 份档 | 200 份档 |
|---|---|---|---|---|
| 命书报告 | 29.99 | 15.00 | 12.00 | **9.00** |
| 合婚详批 | 29.99 | 15.00 | 12.00 | **9.00** |
| 紫微深度 | 24.99 | 13.00 | 10.00 | 7.50 |
| 年运报告 | 19.99 | 10.00 | 8.00 | 6.00 |
| 地理·财富之城 | 19.99 | 10.00 | 8.00 | 6.00 |
| 三合一套餐 | 59.99 | 30.00 | 24.00 | 18.00 |

**伙伴毛利算例**（200 份档，命书）：
```
批发 $9.00 → 伙伴卖 NT$1,500（≈$47）→ 毛利 $38（81%）
           → 伙伴卖 $25  → 毛利 $16（64%）
           → 即使按我们自己的零售价 $29.99 卖，也有 70%
```

## 4-3. 我们的毛利

```
命书售价按 200 档 $9.00 计；AI 生成成本以 aiBudget 实测口径为准（量级为个位数美分/份）
→ 每份毛利 > $8，毛利率 > 90%
★ 真实成本大头不是 AI，是我们的【时间】：v1 阶段每单要人工核对 + 发链接（约 3–5 分钟）
```

## 4-4. 三条价格纪律（防砸盘，写进协议）

```
① 伙伴零售价地板：命书不得低于 $19（或等值 NT$600 / RM90）
   —— 低于这个数，市场会被教育成「命书值 5 块」，我们自己的 $29.99 就卖不动
② 伙伴不得对外宣传「AI 生成」为卖点（可以说「明理引擎」），也不得宣称「准确率 90%」
③ 额度不可转售、不可多人共用同一账号；发现即停额度（余额不退）
```

## 4-5. 首单钩子

```
每个通过审核的伙伴：免费送 2 份（自己 + 一个真实客户）
→ 成本约等于 0，但这是转化率最高的一环：让他们【亲眼看到报告长什么样】
```

# 六、技术方案（v2，v1 只需要 3 处小改）

> **实现状态（2026-10-22）**
> ```
> ✅ 分享令牌 /r/<token>（免登录只读 + 打印为 PDF）—— 已上线并实测：十卷全出、吊销即失效
> ✅ 打印样式 @media print（收在 .hw-print，不波及全站）
> ✅ /partners 落地页（简繁双版 + hreflang）+ 申请表单（落库，非邮件）
> ✅ 运维工具：npm run share:link（建/吊销/查看）、npm run partners:list（查看/推进状态）
> ⛔ 伙伴充值 SKU（partner_credits_10/50/200）—— 卡在 Waffo 后台建商品，拿到 productId 才能接
> 待办：supabase/partners.sql 需在 SQL Editor 跑一次，否则申请表单返回 500
> ```


## 6-1. v1 需要的三处改动（小）

```
① 分享令牌：/r/<token> 免登录只读报告页
   · token = 32 字节随机串，存 reports.share_token，90 天有效，可吊销
   · 页面 noindex（robots + meta），不显示用户邮箱/命盘原始输入
② 打印样式：@media print —— 隐藏导航/按钮，页眉位留给伙伴品牌
③ 伙伴充值 SKU：pricing.ts 加 partner_credits_{10,50,200}（走现有 Waffo 收银台）
```

## 6-2. v2 数据结构（新表，不改现有表）

```sql
partners(id, user_id, status, brand_name, brand_logo_url, tier, default_locale, created_at)
partner_credits(id, partner_id, delta, reason, ref, created_at)   -- delta 可负；余额 = sum
partner_orders(id, partner_id, sku, report_id, share_token, expires_at, created_at)
```

- **不新建支付**：充值走现有 `createCheckoutSession`，webhook 落 `partner_credits`
- **复用引擎**：`aiAnalysis / aiZiwei / aiHemun / aiGeo / aiLiunian` 一行不改
- **繁体**：`default_locale` 直接喂给上一轮做好的 `localeDirective` → 台马伙伴默认出繁体
- **额度校验**：`entitlement.ts` 加一个 `partnerCredit` 分支，与现有四源并列

## 6-2-1. 两个已知的结构约束（现在写清，开工时不用再摸）

```
① reports.user_id 是 NOT NULL（schema.sql:145）
   → 伙伴提交的报告只能挂在【伙伴自己的账号】下；客户通过 share token 看，
     不需要客户注册。绝不为客户建影子账号（会污染用户表与统计）。
② reports 现有 RLS 按 user_id 隔离
   → /r/<token> 必须走服务端 service_role 按 token 查一行（只取 title/result/created_at），
     不能把 anon key 暴露给这个查询；token 建议 32 字节随机、单行唯一索引、可吊销、90 天过期。
```

## 6-3. 明确不做

```
✗ 自定义域名 / 白标子域（绑定与 SSL 的运维成本 >> 收益）
✗ 伙伴自建定价页（他们自己定价，我们不管零售端）
✗ 伙伴端 AI 生文改写（会把合规层绕过去）
✗ 服务端 PDF（等 B 档，且先验证 ≥10 个活跃伙伴）
```

# 七、合规与风控（红线，逐条可查）

```
① 报告正文一字不改 —— 伙伴只能改品牌位。★ 我们已有禁用词层（必/一定/注定/积极进取 等），
   这是卖点：「这份报告敢直接发给你客户」，但只在我们不改正文的前提下成立。
② 免责声明必须在报告首尾各一次，伙伴不得删除或弱化。
③ 不得宣称：准确率、预测未来、医疗/投资/婚姻决策依据、AI 算命。
   对外统一说「传统命理文化分析，仅供参考娱乐」。
④ 客户生辰数据：伙伴是**收集方**，须取得客户同意并告知用途；我们是**处理方**。
   → 伙伴协议里必须写明，且我们不留伙伴客户的邮箱与联系方式（只留命盘与报告）。
⑤ 大陆伙伴暂不接：付款需国际卡（双币卡可，但客群合规风险最高）。
⑥ 不得用于：婚姻决策、投资决策、疾病诊断、未成年人。
```

# 八、获客打法（冷启动 30 天，目标 3 个付费伙伴）

## 8-1. 渠道顺序（按回复率排，不按热闹排）

| # | 渠道 | 怎么找 | 预期回复率 |
|---|---|---|---|
| 1 | **IG / Threads 台港命理师** | 搜 `#紫微斗數` `#八字` `#命理` `#批命`，挑 1k–30k 粉、**有在接单**（简介有报价/Line 链接） | 10–20% |
| 2 | **马来西亚华人命理师** | FB 社团 + 小红书（马来华人多）+ Google Map「命理/風水」 | 5–10% |
| 3 | **YouTube 命理频道** | 中文命理频道评论区/商务邮箱；挑 5k–100k 订阅、更新中 | 3–5% |
| 4 | 台湾紫微/命理学会活动 | 年会、讲座、社群 | 高但慢（季度级） |

## 8-2. 30 天节奏

```
D1–D3   物料：一页纸（附录 A）+ 报告样本链接 + 价目表 + 3 版 DM 话术
D4–D10  DM 20 人（每天 3–4 个，别群发）；目标：5 个回复
D11–D17 给回复者发【免费 2 份】，让他们拿自己/熟客的盘试
D18–D30 促成 3 个付费（10 份档即可，$150）；同时人工跑单，记录每单耗时与客户反馈
★ 停止条件：DM 30 人 < 5 个回复 → 渠道错了，换渠道，【不要先建系统】
```

## 8-3. ★ 一个反常识的点

**不要找大 V**。10 万粉的命理博主有自己的团队与法务，决策链长、要求多、还要求独家。
**1k–30k 粉、自己在接单的个人命理师**才是我们的客户：他一个人决策，今晚就能试。

老師您好，冒昧打擾。我是明理（mingcharts.com）的開發者。
