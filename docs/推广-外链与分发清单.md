# 外链与分发清单（2026-10-23）

> 面向：mingcharts.com 的自然流量增长
> 现状事实（GSC 实测）：sitemap 1254 条 URL，**只有 91 个拿到过曝光**；平均位置 12.1；
> 繁体页开始拿点击（5 点击/日中 4 个是繁体）。
> 结论：**内容不是瓶颈，域名权重是瓶颈。** 新域名（1 个月）在 Google 眼里还没有"被引用过"的证据。

---

# 一、先明确一件事：外链不是"发链接"

真正起作用的外链只有一种：**别人在自己的内容里，主动引用你做的某个东西。**

所以本清单的逻辑不是"去哪里提交网址"，而是：

```
先做出「值得被引用」的东西 → 再让需要它的人看见 → 他们自己会引
```

按这个逻辑，分三类，**按"你能自己控制的程度"排序**：

| 类 | 类型 | 你要做的事 | 见效 |
|---|---|---|---|
| A | **分发**（你完全可控） | 把内容搬到台港平台，带原文链接 | 2–4 周 |
| B | **可引用资产**（产品侧） | 做一页别人写文时会引用的表 | 4–8 周 |
| C | **关系**（需要对话） | 找 3–5 个已有流量的同行，给价值换提及 | 4–12 周 |

## A-1 借道投稿（新首选，门槛最低）

不是"求转载"，是**给内容**。台港很多命理博主缺稿不缺平台。

**投稿邮件模板（照抄，改称呼）**：

```
X 老師您好，

我是明理（mingcharts.com）的开发者，做传统命理的数字化工具，
站上有 89 篇命理知识文，主要是神煞查法、格局用神这类「查得到答案」的题目。

想投一篇给您，您觉得合适就发，不合适直接删掉也没关系：
《红艳煞怎么查：三步从四柱里找出来》（约 1800 字，附两版配图）

只有一个请求：文末作者栏写一句「作者：明理 mingcharts.com」就行，
不必推荐任何服务，也不必回链。

附上全文与配图，您可以直接用。
```

**要点**：

```
✓ 给完整成品（全文 + 图），不要让对方"来你站上看"
✓ 只要作者栏署名，不要回链（"不必回链"这句反而更容易被链接）
✓ 一次只投一篇，别附 6 篇（像投广告）
✓ 投 5 个，有 1 个用就很值
✗ 不要要求"必须保留原文链接""不得删改"
```

## A-2 自助平台（借道不通时用）

## A-3 搬运规则（**违反会被判垃圾内容，比不发更糟**）

```
✓ 一篇文章只搬到一个平台，不要 89 篇一次性搬空
✓ 每周 2 篇，持续 4 周（10 篇左右），观察收录与流量
✓ 正文重写开头 100–150 字（不能原文照搬 —— 重复内容会互相打架）
✓ 结尾放一条原文链接：「完整版（含 2024–2031 太岁对照表）在 mingcharts.com」
✓ 标题可以换，但关键词要保留（「紅豔煞查法」这类具体词别改）
✗ 不要每篇结尾用同一段 CTA 文案（模板会显得像站群）
✗ 不要在一篇里塞 3 个以上本站链接
✗ 不要在平台上写「免费」「不用注册」这类导流句（各平台规矩不同，先按最严的写）
```

# 三、B 类：做「值得被引用」的一页（产品侧，我能直接做）

## B-1 为什么是这个：太岁对照表

现在我们有 96 个流年页（12 生肖 × 8 年），但它们是**分散**的。
一个写「2027 年运势」的博主，需要的是**一页看到 12 个生肖那年犯不犯太岁**——
这正是最容易被人引用、且只此一家的东西。

新页面：`/liunian/taisui-biao`（繁体 `/tw/liunian/taisui-biao`）

```
内容：一张表，行=12 生肖，列=2024–2031，格=值/冲/害/刑/合/平
附带：每格的链接指向对应生肖流年页（内链收益）
再附带：可下载的图片卡片（1200×630），方便博主直接贴图引用
```

**为什么它能带来链接**：写流年文章的人需要这张表，而自己去做很麻烦。
他们引用时会链接（哪怕只是"来源：明理"）。

**这个我可以直接做**（中等工作量，一页 + 数据 + 图片卡片 + 测试）。

## B-2 第二个可引用资产：真太阳时校正器（技术向）

我们代码里的 `solarTime.ts` 处理了**中国 1986–1991 夏令时、各国历史时区偏移**——
这是技术圈会觉得有意思的东西。可选动作：

```
把一个「真太阳时」小工具页做成可链接资产：
输入城市 + 钟表时间 → 输出真太阳时（纯前端，不花钱）
```

它命中「真太阳时怎么算」这类查询，也容易被技术博客/命理博客引用。
**风险**：这类工具站很多，不稀缺。**优先级低于太岁表。**

# 四、C 类：关系型外链（需要你亲自谈，成本最高）

## C-1 三种谈法，按成功率排

| 谈法 | 给对方什么 | 成功率 | 说明 |
|---|---|---|---|
| **给他做一份免费的盘/命书** | 一份万字报告 | 中 | 你已经会做（送 2 份额度） |
| **客座文章** | 一篇独家文（不重复站内） | 中低 | 需要对方有博客且愿收稿 |
| **数据/表格授权** | 允许他免费用太岁表 | 中高 | 降低他的成本，他自然标来源 |

★ 最实用的是第三种：**B 类的表做出来之后，主动告诉 5 个写流年的博主"这张表你可以随便用，标个来源就行"。**
这比"求个链接"自然得多。

## C-2 目标类型（不是具体名单，名单要靠你自己搜）

```
· 台湾/香港命理博客（有 5 年以上更新史、非纯广告站）
· 命理 YouTube 频道（1 万–10 万订阅，简介栏放链接）
· 命理 Podcast（如你名单里的「紫玄紫微」）
· 马来西亚命理社团/公会
```

## C-3 开口模板（三句话，别长）

```
您好，我做了一个免费工具：mingcharts.com，能排八字并出一份万字命书。

最近整理了一张《2024–2031 十二生肖太岁对照表》（12×8，一眼看完谁犯太岁）。
想请您免费用，您写流年文的时候如果方便，标一句来源就行，不用特意推广。

表格在这里：<链接>
```

**关键**：不要求回报，只要求"方便时标来源"。要链接的请求越轻，成功率越高。

# 五、绝对不做（做了会伤站）

```
✗ 买链接 / PBN / 站群 —— 新站最容易因此被降权，且不可逆
✗ 批量目录提交（"免费收录网址"那种站）—— 零权重、有风险
✗ 评论区刷链接（论坛、YouTube、博客评论）—— 无效且败品牌
✗ Wikipedia 加外链 —— 会被删，且可能被标记
✗ 一次性把 89 篇搬空 —— 触发垃圾内容判定
✗ 用同一个锚文本（"八字算命"）反复指向首页 —— 典型的操纵痕迹
```

**锚文本要有自然分布**：

```
主页      → mingcharts、明理、mingcharts.com
工具页    → 免费排盘、八字排盘工具
对照表    → 太岁对照表、2027 犯太岁
文章页    → 红艳煞查法、空亡怎么看
```

| 第 3 周 | **太岁对照表上线**（B-1） | 新页面 + 图片卡片 |
| 第 3 周 | 主动告知 5 个写流年的博主"表可免费用" | 发出 5 封 |
| 第 4 周 | 跟进未回的博主一次；FB 命理社团答 3 个问题（带太岁表） | 累计 4–6 篇上线 |
| 第 4 周 | 复盘：GSC 链接报告 + 各平台流量 | 记录首次引用域数 |

**目标（诚实区间）**：

```
30 天：3–5 个真实引用域（含平台主页/文章页），分发带来 50–200 次访问
60 天：8–12 个引用域，长尾词曝光从 91 页涨到 150–200 页
```

**这不是"涨 10 倍流量"的计划**，是**把域名从"没人引用过"变成"有人引用过"**的计划。
权重起来之后，同样的内容排名会自己往上走。

# 七、怎么量（每周 10 分钟）

| 看什么 | 在哪 | 判断 |
|---|---|---|
| 引用域数 | GSC → 链接（有 2–3 周延迟） | 涨了就是有效 |
| 分发平台流量 | 各平台后台 | 有阅读但没点击 → 结尾 CTA 要改 |
| 新页面收录 | GSC → 网页 → 已编入 | 分发文章里的链接是否被发现 |
| 曝光页面数 | GSC → 效果 → 网页（数量） | 从 91 往上涨是核心指标 |

★ **每周只看一次**。外链的反馈周期是 4–8 周，天天看只会误判。
