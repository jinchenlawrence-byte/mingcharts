## 二、v5 正文（删掉「十卷」这类产品结构描述）

```
我是命理师，也是这套引擎的作者。

最耗时间的从来不是看盘，是把看出来的东西写下来。

格局、调候、用神、大运流年、事业婚姻子女健康，
一样一样讲清楚，不能漏项；每条断语还得说得清依据，出自哪本书哪一句。
一份写完三小时，连写三份就写不动了，而且越写越容易漏。

所以我自己写了个引擎：
四柱、十神、藏干、起运按真太阳时算清楚；
按固定的工序走，不会漏项；
每条断语记下依据，回头能查。

现在我十分钟出初稿，剩下的时间全花在两件事上：
核对我不同意的断语、补这个盘特有的那几句话。

——不是我算得更准，是我不容易漏。

你们批一份命书，最容易漏的是哪一部分？
```
