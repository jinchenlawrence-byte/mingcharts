## 一、被判违规的具体位置（对照平台给的理由）

| 平台规则 | 对应我们文案/图片 | 结论 |
|---|---|---|
| 文本违规：「存在尝试引导他人前往其他平台进行搜索、浏览或查看的行为」 | **「排盘免费，不用注册。」** | 这句话就是一个明确的"去站外用"指令，比网址更直接 |
| 图片违规：规则 1「存在展示其他平台界面信息的行为」 | **02 产品截图**（整页网页 UI） | 一张网页截图 = 其他平台界面 |
| 图片/文本：规则 3「通过种草、科普、教程等方式为其他平台宣传介绍」 | 「同行想用这套体例出报告，也可以找我」 | 招揽性质 |
| 规则 5「对其他平台的产品、服务、付费内容进行推荐」 | 同上（付费报告属站外付费内容） | — |

**根因**：我反复强调"不要放网址"，却漏了「免费 / 不用注册」本身就是引流 ——
它给了对方一个动作，比网址更难辩解。

## 二、v4 正文（已删掉三处违规内容）

```
我是命理师，也是这套引擎的作者。

一件事做了几年，最耗时间的从来不是看盘——
是把看出来的东西写成一份万字命书。

格局、调候、用神、大运流年、事业婚姻子女健康，十卷要铺开；
每条断语还得说得清依据，出自哪本书哪一句。
一份三小时，连写三份就写不动了，而且越写越容易漏。

所以我自己写了个引擎：
四柱、十神、藏干、起运按真太阳时算清楚；
十卷体例固定下来，不会漏项；
每条断语标注所引经典，回头能查。

现在我十分钟出初稿，剩下的时间全花在两件事上：
核对我不同意的断语、补这个盘特有的那几句话。

——不是我算得更准，是我不容易漏。

你们批一份命书，最容易漏的是哪一部分？
```

**删掉的**：`排盘免费，不用注册。` / `同行想用这套体例出报告，也可以找我。`
**改掉的**：结尾从「招揽」变成「提问」。

**保留的**：引擎、十卷、真太阳时、标注出处 —— 这些是**方法论描述**，不是导流。
（仍在灰区边缘：描述自己的站外工具仍可能被规则 3 沾到。若二次审核仍限流，只能删。）

## 三、替换图（02b-classics.png）

原来那张网页截图换成「两条立命之基」古籍卡：

```
八字用神，专求月令。          ——《子平真诠》沈孝瞻
何知其人富，财气通门户。      ——《滴天髓》
```

为什么换它：
- 纯内容，无界面、无产品名、无使用引导
- 对同行反而更有价值（两句都是判断时的第一原则）
- 承接正文那句「不是我不够仔细，是原则没兑现」

## 四、账号恢复期纪律（重要）

```
✗ 不要申诉 —— 判对了，申诉会被驳，还可能加深审核印象
✓ 点「修改笔记」改内容，走二次审核
✗ 三天内不要再动号：不改资料、不发第二条、不私信
✓ 正常浏览、点赞、收藏别人的内容，让它像真人
```

**第二次违规代价远高于第一次**（可能禁言/封号）。现在这个号背着一条违规记录，
后续任何"引流"嫌疑都会从重处理。

## 五、由这件事得出的策略调整

**小红书从「获客渠道」降级为「身份页」。**

原因：命理内容本身敏感 + 站外产品 = 双重风险，每发一条都在走钢丝；
而我们要它做的只是一件事——**让对方点进主页时，知道这是个真人、懂行、在做产品**。

所以：

1. **不再为小红书生产内容**（除偶尔一条纯知识分享）
2. **联系伙伴改走对方官网表单/邮件**（首选），而不是靠平台内私信
3. 私信仍可用，但**只发文字、不发链接、不发图片、不提"免费/注册"**
4. 若以后要做内容矩阵，考虑公众号/知乎（对命理类内容更宽松），小红书不做主战场
