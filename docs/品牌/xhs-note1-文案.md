## 正文

```
我是命理师，也是这套引擎的作者。

一件事做了几年，最耗时间的从来不是看盘——
是把看出来的东西写成一份万字命书。

格局、调候、用神、大运流年、事业婚姻子女健康，十卷要铺开；
每条断语还得说得清依据，出自哪本书哪一句。
一份三小时，连写三份就写不动了，而且越写越容易漏。

所以我自己写了个引擎：

四柱、十神、藏干、起运按真太阳时算清楚；
十卷体例固定下来，不会漏项；
每条断语标注所引经典，回头能查。

现在我十分钟出初稿，剩下的时间全花在两件事上：
核对我不同意的断语、补这个盘特有的那几句话。

——不是我算得更准，是我不容易漏。

排盘免费，不用注册。

同行想用这套体例出报告，也可以找我。
```

## 为什么是「不容易漏」而不是「更准」

作者的原话是想「得到更准确快速的结果」。但对外必须换个说法，两个原因：

1. **合规**：报告生成链路本来就禁「必 / 一定 / 注定」这类承诺措辞（禁用词层），对外也不该承诺准确率。
2. **可信度**：「算得更准」是无法验证的自我评价，读者会打折；
   「不容易漏」是**可验证的机制描述**——十卷不漏项、每条带出处，读者自己就能判断真假。

这句话同时是最强的卖点：**它的承诺落在"稳定性"上，而不是"神准"上。**

## 定位复盘（v1 → v2 → v3）

| 版本 | 说法 | 问题 |
|---|---|---|
| v1 | 「书能看懂，盘看不懂」 | 把作者写成新手；与产品矛盾；不属实 |
| v2 | 「我不是命理师，是产品经理」 | 仍在装外行 —— **作者本来就是命理师**，这是假话 |
| **v3** | 「我是命理师，也是写这引擎的人」 | 真实，且是三种身份里对同行最有说服力的 |

v3 顺带解决了最难回答的问题：
**「你凭什么说报告够格交给客户？」** —— 因为我拿它交付我自己的客户。

## 已知取舍

- **不出现「算命」**：小红书对玄学限流严，用「命理师」「排盘」更安全。
- **不提价格**：第一条笔记是建立身份，不是卖东西。
- **结尾那句「同行想用这套体例出报告，也可以找我」**：不写"合作/代理/分成"，
  用同行之间的说法 —— 真有兴趣的人会来问，没兴趣的人不觉得被推销。
