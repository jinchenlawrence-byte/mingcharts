# 二、必须照抄的事实（A 侧已核实，不要改写、不要补充别的）

## 2-1. 五条硬事实

```
① 真太阳时 = 当地钟表时刻 + (出生地经度 − 当地【出生当时】实际 UTC 偏移小时 × 15) × 4 分钟
② 每差 1° 经度 = 4 分钟
③ 时区中央经线：UTC+8 → 120°E ；UTC−5 → 75°W ；UTC−4 → 60°W
④ 夏令时不是「永远 +1 小时」的历史约定：
   美国自 1967 年起实施（Uniform Time Act 1966）；中国 1986–1991 年实行过；
   各国/各州起止年份不同，必须以出生那年那月的实际规则为准
⑤ 本站采用【平太阳时近似】，未计入均时差（equation of time，±16 分钟内）——
   这一点必须在文中如实写明，不许含糊或省略
```

## 2-2. 三处必须与实现对齐（写完要实跑核对）

```
① 「未计均时差」这句话必须与 src/lib/solarTime.ts:9 的注释一致
   （那里写的是：此为平太阳时近似，未计入均时差，命理排盘层面足够）
② 文中「夏令时按出生日期自动判定」的说法，必须能在代码里找到依据
   （src/lib/solarTime.ts 的 getUtcOffsetHours / toTrueSolarTime）
③ ★ 文中每一个具体数字（分钟数）都必须由实跑 trueSolarOffsetMinutes() 得出，
   不许手算、不许估算。回执里要贴出实跑输出与文中数字的对照表
```
