## 3-1. 2028 的关键日期（A 侧已用项目自带 lunar-javascript 实算，写进页面与文案）

```
2028 农历正月初一（春节）= 2028-01-26        ← 生肖／民俗边界
2028 立春（命理年柱切换） = 2028-02-04 15:31  ← 命理边界，精确到分钟
```

★ **两个边界相差 9 天**（不是 2027 那样只差 2 天），所以这一年「屬相到底哪天換」的争议更明显，
文案里必须把两个日期都写出来，并说明各自适用场景。

★ 立春是**时刻**不是整日：2028-02-04 当天 15:31 之前出生仍是丁未年，之后才是戊申年。
A 侧已实测：`2028-02-04 12:00 → 丁未`、`2028-02-04 21:00 → 戊申`。
**文案若要提"立春当天要按时辰算"，这句必须准确；不确定就只写日期、不写时刻。**

★ 实现要求：**不要凭记忆写任何日期**。春节用 `Lunar.fromYmd(2028,1,1).getSolar()`；
立春用 `Solar.fromYmd(2028,2,4).getLunar().getJieQiTable()` 取「立春」那一项。
**若实算结果与上面不一致，以实算为准并在回执里写明差额。**
