# 五、修法（三条，按优先级）

## 5.1 ★★★★ 根治：prompt 从判据**派生**，不再手抄

```ts
// src/lib/ai-check.ts —— 新增导出
export const FORBIDDEN_WORDS_PROMPT =
  `以下词语一律禁用：${FORBIDDEN_WORDS.join('、')}（"必"含务必/必然/必定）。\n` +
  `逐字替换范例：务必→宜；必然/注定→往往；必定→多半；一定→往往；大吉→较为有利；` +
  `积极进取→稳中求进；突破性进展→阶段性的进展。`

// 四个模块的 SYSTEM_PROMPT 用模板串拼入
import { FORBIDDEN_WORDS_PROMPT } from './ai-check'
const SYSTEM_PROMPT = `…\n3. 断语留余地…\n   ${FORBIDDEN_WORDS_PROMPT}\n4. …`
```

**★ 效果**：**改了判据 → 四个 prompt 自动同步** ✓ 漂移在结构上不再可能 ✓

## 5.2 ★★★ 加断言守护（这才是能防复发的）

```
新增断言：遍历四个 AI 模块，断言其 SYSTEM_PROMPT 文本【包含 FORBIDDEN_WORDS 全集】
★ 这是一条【结构性断言】—— 它不查"某个词在不在"，而查"判据与 prompt 是否同源"
★★ 牙口：从任一模块的 prompt 里删掉一个词 → 该断言必须精确翻红
   ★ 用【文本不变、行为变坏】的改法优先；但这里是文本断言，
     所以注入选"删掉一个词"是合适的 ✓（它就是要抓文本缺失）
```
