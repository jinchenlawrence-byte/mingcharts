# 二、步骤 ①：cap 分级改为 (ii)

## 2.1 改动（一处 ＋ 注释同步）

```ts
// src/lib/analysis.ts —— fortuneTierOf
// 现状

  structuralIssues.length === 0 ? 4 :      // 无结构病 → 可达「大吉」

// ★★★ 改为

  structuralIssues.length === 0 ? 4 :      // 无结构病 → 可达「大吉」
```

```
② ★ 注释第二支：最高「小吉」→ 最高「吉」✗
   —— 因为它【本来就不符】✗（新阈值下 min(s,2)=2 对应「吉」✗）
```
