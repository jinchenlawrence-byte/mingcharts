### 5.2 规则引擎设计

**五类城市**：

| 类别 | 目标十神 | 关系 | 图标/色 |
|---|---|---|---|
| 💰 财富之城 | 身旺→财星 / 身弱→比劫 | 我克 / 同我 | `#d97706` |
| 🏛️ 事业之城 | 身旺→官杀 / 身弱→印星 | 克我 / 生我 | `#7c3aed` |
| 🤝 贵人之城 | 印星 | 生我者 | `#0891b2` |
| 🏠 安居之城 | 比劫 | 同我者 | `#059669` |
| 🎨 才华之城 | 食伤 | 我生者 | `#db2777` |

**身弱不任财官修正**（核心改动）：
- 身弱时，财富之城不取财旺之地，改取 **比劫帮身之地**（同气相扶方能担财）
- 身弱时，事业之城不取官杀之地，改取 **印星扶身之地**（化杀生身、先立根基）
- 身旺才直取财官，AI 与规则文案均随旺衰切换

**评分体系**：
- 基础 50 分
- 城市主气合目标 +28、为喜用 +8、为忌 -15
- 次气合目标 +10
- 出生地 30km 以上论 Haversine 距离 + 八卦方位角（合目标 +6）
- 影响分五档：≥82 强旺大吉 / ≥70 助力显著 / ≥58 可以借势 / ≥45 助力一般 / 偏弱

**AI 纪律**：
- 只引用规则引擎事实，不编造城市/干支关系
- 强调"福地福人居、个人努力为本"，不搞迷信恐吓

### 5.3 地图技术

- **d3-geo 墨卡托投影**，离线 SVG 渲染
- 国界轮廓 + 经纬网格 + **中国暖黄高亮**
- 彩色城市标记（首城显示 emoji，其余显示城市首字）
- 点击标记弹出详情卡（城市、五行、指数、方位、论据）
- 灰色 ★ 标记出生地
- **零网络瓦片请求**，秒开且永不空白（Leaflet 已卸载）
