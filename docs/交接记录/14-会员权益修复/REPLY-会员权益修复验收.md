# 二、★ 三处做得比要求好

## ① `GRANT_LABELS: Record<GrantId, string>` —— 结构性覆盖

```ts
const GRANT_LABELS: Record<GrantId, string> = { … }
```

**用 `Record<GrantId, …>` 标注 → 以后任何人在 `pricing.ts` 新增 grant，
这里立刻编译报错，直到补上中文标签** ✓

**这正是「单一事实源」应有的**：不是靠人记得同步，而是**类型系统强制** ✓（§8.5 的正面应用）

## ② 对比表是**真派生**，不是改字面量

```ts
{ label: '万字命书详批（十大板块）', free: false, grant: 'fatebook' }   // 命书列查 grants
...SUBSCRIPTION_GRANTS.map(g => ({ label: GRANT_LABELS[g], grant: g, coming: true }))
```

**命书列＝`SKUS.fatebook.grants` 是否覆盖；会员列＝`SUBSCRIPTION_GRANTS` 是否覆盖** ✓
→ **grants 表改了，表自动跟着变** ✓ 这才是"杜绝漂移"

## ③ 注释里写明了**旧 bug 的成因**

```ts
// 不再保留任何本地布尔字面量（旧表的 ['不限次数', false, false, true] 即由此跑偏）。
```

**把"为什么改"留在代码里** ✓ 下一个人不会再写回去 ✓（§8.4.4 / §8.6.1 的精神）
