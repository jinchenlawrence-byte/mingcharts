# 三、★★ 而它留下的状态是【不一致的半成品】—— 这比不改更糟

## 3.1 实测证据

`pricing.ts` 的数据源**已改对**：

```ts
member_monthly: {
  desc: '个性化日运（每日）＋ 流月提示，持续更新',   // ✅ 已改
  grants: SUBSCRIPTION_GRANTS                        // ✅ 不含报告
}
```

**但 `/pricing` 页面实测仍是旧文案**（我方 HTTP 抓取）：

```
含「不限次数」: ★ 是
★ 仍含旧文案：「命书不限次数」
★ 仍含旧文案：「免费解锁完整命书」
```

**→ 数据源说"订阅不含报告"，页面还在说"命书不限次数"** ✗ **自相矛盾。**

## 3.2 根因：**页面只把「价格」接到了 SKUS，「文案」仍是本地硬编码**

```tsx
// src/app/pricing/page.tsx —— 价格取自 SKUS ✓
price: formatPriceUSD(SKUS.member_monthly.priceUSD)     ✓

// 但卡片文案是本地字面量 ✗
desc: '重度用户更划算，命书不限次数',                    ✗ 不随 SKUS 变
'本账号命书报告不限次数',                                ✗
q: '会员期内命书不限次数是什么意思？',                    ✗
['不限次数', false, false, true],                        ✗
```

**→ 所以改了 `pricing.ts` 的 `desc`，页面一点不变** ✓

**★ 这与「单一事实源」的目标相违**：价格单源了，**权益描述没有**。
**修法**：页面的权益列表/FAQ 也应从 `SKUS[].grants` 派生，或至少在注释里标明
「本页文案必须与 pricing.ts 的 desc/grants 同步」✓
