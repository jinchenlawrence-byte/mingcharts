# 二、★ 为什么这段描述要这么写（三个目的）

```
① 如实描述产品
   —— 审核方最怕的是"申报与实际不符"，而不是"产品题材特殊" ✓

② ★★ 主动声明「不提供真人服务」
   —— 这是 Waffo 唯一的硬性红线（"不得是人的时间"）✓
      主动写出来，等于提前回答了审核最关心的问题 ✓
      × 若等他们问，就从"透明"变成"被质疑"了

③ 展示合规意识（AIGC 披露 / 依据分级 / 免责 / 不承诺结果）
   —— 让审核方判断"这是一个会被投诉的站，还是一个懂规矩的站" ✓
```

**★★ 而且要如实写出"命理"** —— 不要回避 ✗

```
· Waffo 文档把 Divination & Fortune-Telling 列为【restricted（限制类目，需审核）】
  —— 【不是 prohibited（禁止）】✓
· 所以如实写不会导致封号，而是进入【人工审核】✓ —— 这正是我们要的
· ★ 回避措辞反而危险：万一被看出来，就从"透明"变成"隐瞒" ✗
```
