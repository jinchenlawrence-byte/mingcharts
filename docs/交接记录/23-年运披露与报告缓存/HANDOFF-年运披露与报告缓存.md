# 三、步骤 ②：加缓存（主体）

## 3.1 ★★★★ 设计原则（三条，§〇-3/4/5 ✗）

```
① ★★★★★ 【缓存只存内容 ✗ 不存权益状态**✗
   · 存：`free`（结构化岁运事实 ✗ 试吃用 ✓）＋ `ai`（AI 全文 ✓）
   · 【不存：`locked`**✗ —— 它【每次按当前权益重算**✓
   → ★★★★ 这样【"先试吃、后付费"才能正确工作**✓

② ★★★★ 【缓存键必须显式含算法版本**✗
   ```ts
   // src/lib/reportCache.ts（新文件 ✗ 设计成可复用）
   /** ★★★ 改动【AI prompt / 判据 / 排盘算法】任一时必须 +1（否则旧缓存与新规则矛盾） */
   export const ANNUAL_CACHE_VERSION = 1
   ```
   · 键 = `annual` ＋ `v{VERSION}` ＋ `targetYear` ＋ 【八字与时间参数全量**✗
     （★ 必须含【时区/经度/真太阳时相关字段**✗ 而不只是年月日时 ✓）

③ ★★★ 【用覆盖写 ✗ 不新增行**✗
   · 同一（user_id ✗ kind ✗ cache_key）【只保留一行**✓
   · ★★ 重生成时【更新该行**✓ 不 insert 新行 ✓
   → ★★★ 那【顺带修掉"重复点击堆积重复行"**✓（§1.3 的现存问题 ✓）
```
