# 二、步骤 ①：补齐四柱覆盖（根因）

## 2.1 检查什么

**现状**（`buildLuckLiuNian`，:991-1019）：

```
日支（夫妻宫）：冲 / 合 / 伏吟 / 半合      ← 已有 ✓
月支（提纲）  ：冲 / 合                    ← 已有 ✓
日柱          ：整柱伏吟                   ← 已有 ✓
日干          ：天干五合                   ← 已有 ✓
```

**要增补**：

```
★ 年支：冲 / 合 / 伏吟 / 半合
★ 时支：冲 / 合 / 伏吟 / 半合
★★ 年柱 / 月柱 / 时柱：整柱伏吟（不止日柱）
★★ 年干 / 月干 / 时干：天干五合（不止日干）
```

**★★★ 实现要点（易错）**：
```
① 现在是【互斥 else-if 链】✗（一个支只报一种关系）
   → 对【每一柱各自跑一遍】该链 ✓
② ★★ 【不同柱可以同时有关系】✓ —— 如 2019：年柱半合 + 时柱六合 ✓
   → 不得因为一个柱命中就跳过其他柱 ✗
③ 伏吟要分两种：
   · 整柱伏吟（天干地支都同）✓ —— 2022 壬寅 vs 时柱壬寅 属此类
   · 同支伏吟（只地支同）✓ —— 建议也报，措辞区分开
```

## 2.2 ★★★★ 计分与权重（本任务最需要判定的地方）

**我方选择：年柱/时柱的关系【计入 score】** ✓ 理由：

```
· 不计入 → 信息变丰富 ✓ 但【判词仍会是「平」】✗ —— 那正是用户报的问题 ✗
· 计入   → 该用户 2019 会 +2、2023 会 +1 → 判词【真的会动】✓
★★ 依据：流年与四柱的冲合【是命理常论】✓ 不是本产品发明 ✓
   ★★★ 但【依据等级须标注为「通行做法」】✓ 不得声称古籍明文 ✗（§8.6.2）
```

**★ 建议的权重（与既有部分保持一致，不另造标度）**：

| 关系 | 分数 | 措辞（须含柱名） |
|---|---|---|
| 冲（任一支） | −1 | `流年支${z}冲${柱名}${pz}，…` |
| 六合（任一支） | +1 | `流年支${z}合${柱名}${pz}，…` |
| 半合（助喜用） | +1 | `流年支与${柱名}${label}，合出${ju}气助喜用` |
| 半合（助忌神） | −1 | 同上，改为"助忌神" |
| 整柱伏吟 | 0（只报描述） | `流年与${柱名}伏吟，…` |
| 同支伏吟 | 0（只报描述） | `流年支${z}与${柱名}伏吟，…` |
| 天干五合 | 0（只报描述） | `流年干${g}与${柱名}${pg}相合，…` |

**★★ 注意：伏吟与天干五合【不加减分】✗** —— 因为它们论"反复/羁绊"✓ 无明确吉凶方向 ✓
（现有代码对日柱伏吟、日干相合也是【只 push 描述、不减分】✓ 保持一致 ✓）

**★★★ 各柱的措辞要与命理术语一致**（不得自造名称）：
```
年支 → 「年柱」「祖上/父母宫」
月支 → 「提纲」「月令」                    ← 现有措辞 ✓ 不改
日支 → 「夫妻宫」                          ← 现有措辞 ✓ 不改
```
