## 1.1 审计用的硬规则（本轮继续沿用）

八字历法有两条**硬约束**，不依赖任何外部史料即可判定四柱真伪：

- **五虎遁**：月干由年干唯一确定
- **五鼠遁**：时干由日干唯一确定

```python
GAN='甲乙丙丁戊己庚辛壬癸'; ZHI='子丑寅卯辰巳午未申酉戌亥'
gi=GAN.index; zi=ZHI.index

def wuhu_ok(nian_gz, yue_gz):      # nian_gz/yue_gz 形如 '庚辰'
    s = (gi(nian_gz[0]) % 5) * 2 + 2            # 寅月起月干
    o = (zi(yue_gz[1]) - 2 + 12) % 12 + 1       # 寅=1 .. 丑=12
    return GAN[(s + o - 1) % 10] == yue_gz[0]

def wushu_ok(ri_gz, shi_gz):
    s = (gi(ri_gz[0]) % 5) * 2                  # 子时起时干
    return GAN[(s + zi(shi_gz[1])) % 10] == shi_gz[0]
```

### A.3 质量分级口径（按文件统计双通过率）

| 等级 | 双通过率 | 含义 |
|---|---|---|
| **A** | ≥ 99% | 可放心使用 |
| **B** | 90% – 99% | 逐条核对后可用；不过者须单列 |
| **C** | < 90% | 须重做或标废；**不得作为主要数据源** |

> 分级写在**记录级**（便于筛选），同时在 `index.json` 的**文件级**汇总。

### A.4 硬性要求

- **只加字段，不改干支、不删记录。** 干支是数据，不是你能修的东西。
- 若发现某条干支明显是 OCR 形近误字（如「已」→「己」、「巴」→「巳」），
  **保留原字**，另加 `OCR疑似形近: "已→己"` 字段提示。**不得静默改字。**
- `可用` 的**唯一**含义：`四柱俱全 && 五虎遁 && 五鼠遁`。
  其他文件原有的 `可用` 语义（如"入库即可用"）**须迁移到** `原可用` 字段保留，避免语义丢失。

### A.5 验收

# 三、必须遵守的纪律（沿用第一轮）

## 3.1 不得编造 —— 红线
## 3.2 溯源校验
LLM 给出的四柱必须能在源文连续检出；**跨块拼装须另有归属证据**。
## 3.3 三级标注
`【原文】` / `【本笔记·工程化设定】` / `【存疑】`
## 3.4 版本意识
同名书不同版本价值可能完全不同（例：本地《三命通会》PDF 是现代简化本，**已删光命例表**）。
## 3.5 **不静默改字**
发现古籍讹误（如三命通会 page133「丙辰日**乙**丑時」，五鼠遁下丙日只能是己丑），
**如实保留原文 + 标注**，**不得替古籍改字**。

## 3.6 ⚠️ 最重要的一条边界（本轮必须理解）

> **历法校验只能证明「柱子之间自洽」，不能证明「干支归属于这条命例」。**
> 即：它能防**柱子错位**，**防不住张冠李戴**。

**实例**：三命通会卷八 page13，把不同小节的两列强行配对，得到
「年乙亥 月丁亥 日甲申 时乙丑」——**五虎遁✓ 五鼠遁✓，但人物与日柱全错**。

**所以**：`历法校验通过` 是**必要条件，不是充分条件**。
凡涉及**跨块/跨列拼装**的记录，必须**另有归属证据**（同小节 id、或 `bbox_2d` 邻接证明），
否则不得标 `可用:true`。
