# 一、协作模式

| 角色 | 职责 |
|---|---|
| **DeepSeek 侧** | 规格制定 · 数据审核 · 根因定位 · 独立复算 |
| **TraeCode 侧** | 实现 · 批量处理 · 环境操作 · 产品代码 |

**固定文书流转**：

```
HANDOFF-*        （DeepSeek → TraeCode：任务书）
   ↓
HANDOFF-BACK-*   （TraeCode → DeepSeek：回传结果）
   ↓
REPLY-* / REVIEW-* / ACCEPT-*  （DeepSeek → TraeCode：复核 / 审核 / 验收）
   ↓
下一轮 HANDOFF-*
```

**核心惯例**：DeepSeek 侧**必须独立复算** TraeCode 的自报数字，**不得直接采信**。
（历轮复算多次发现偏差与隐藏 bug，见总纲 §9.1。）
