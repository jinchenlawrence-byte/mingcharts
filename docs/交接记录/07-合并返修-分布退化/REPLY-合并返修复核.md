# 三、★ Q1 裁决：「单一五行占比 <50%」用哪套口径？

## 3.1 我的裁决

**采纳方案 1 的精神，但判据本身要改。三个方案的取舍如下：**

| 方案 | 裁决 |
|---|---|
| 方案 1（推荐结果口径） | ⚠️ **方向对，但判据不对** —— 见 3.2 |
| **方案 2（补约 200 城）** | ❌ **否决** —— 见 3.3 |
| 方案 3（原始池 + 边缘豁免） | ❌ **否决** —— 豁免等于承认缺陷不管 |

## 3.2 判据本身错了（**我的规格问题**）

**总纲 §8.4 规则 ② 是为「固有标签」设计的，不适用于「相对关系」。**

| | 旧模型（城市五行＝固有属性） | 新模型（方位五行＝相对命主） |
|---|---|---|
| 木占比高 | **62%——构造 artifact**，标签形同虚设 → **该判 ✗** | 乌鲁木齐 77% 东——**真实地理事实** → **不该判** |
| 为什么 | 把"相对中国中心的方位"当固有属性，强行贴标签 | 从乌鲁木齐看，中国城市**确实**偏向东南 |

**对"相对某中心"的量，原始池分布必然随观察点变化——这是地理，不是模型缺陷。**

**因此真正的判据应改为操作性的那一条：**

```
★ 每个目标五行（5 类）的可用候选数 ≥ Top-N
   即：每类都能取满推荐位
```

**这也正是 §一② 「标签形同虚设」的本意** —— 标签有没有用，要看**用户实际能不能拿到每类的推荐**，不是看池子里有多少。

## 3.3 为什么否决「补 200 城」

**核心理由：补城解决不了这个问题。**

拉萨正南只有 3 城，**是因为正南是喜马拉雅山脉**——那里没有城市。
**补再多城，拉萨的正南还是那 3 个。**

补 200 座冷门城市只会：
- 稀释推荐质量（远端小城更不相关）
- **仍然修不好那 2/10**（因为缺口在特定方位，不在总量）

**性价比极低且无效。**

## 3.4 正确修法：放宽水火扇区（而非补城）

**水火各占 45°、木土金各占 90° —— 应该把这个不对称抹平。**

建议：**候选门控按「五行扇区」而非「卦扇区」**，
水火各纳入相邻一个卦作为**次方位**（如正北 + 东北／西北的一部分），
使五类的候选池宽度均衡（各 72°–90°）。

**依据**：

> **方位五行的传统用法本就是宽泛的「南方／北方／东方／西方」，不是 ±22.5° 的卦界。**
> 精确到卦是**「方位标签」**的需要（如「西南·坤土」这种细化描述），
> **不是「五行门控」**的需要。

**替代方案**（若你倾向不改扇区）：

- **接受取不满，但降级展示并标注**——如拉萨的火城显示「正南候选较少（3 城），已列全部」，
  **不得静默少显示**（当前已如实报出，保持即可）

**两者取其一，我略倾向前者（放宽扇区）** —— 因为它让"每类都能取满"成为**结构保证**，
与 §2.3 修方位退化时的思路一致。

# 四、Q2 / Q3 答复

## Q2：丁亥型（财透坐劫）判「平」是否符合预期？

**答复：判「平」是对的，请保持。**

我任务书 §3.3 表格写的是「财星透干 → 【平】」+ 措辞「财现但比劫夺之——进财机会与破耗并存」。
**丁亥正是该描述的典型**：财透了（机会来了），坐支比劫（守不住）。

你选择的「财现优先于坐支劫」**符合预期**。理由：

- 判「滞」会**丢掉"机会来了"这个信息**，又滑回"过度宿命"（那正是 §三要修的）
- 判「平」+ 点明「财现坐劫地、易来易破」是**信息量最高**的处理 ✓

**无需调整优先级。**

## Q3：命局底色是否在财运维度保留一句简注？

**答复：不加。** 理由：

- 任务书 §3.3 明确要求「原局特征在命局总论说一次；时段维度只讲该时段带来的变化」
- **重复 9 遍正是要修的病症**（"从 3 岁到 83 岁全说求财费力"）
- 每步大运末尾加半句 = **变相重复**，会让"恢复区分度"的努力打折

**若担心跳读，正确做法是在大运段的整体开头加一次指引**（如「各步财运详见上节【财运底色】」），
**而不是每步都加**。
