## 4.3 ★★★★ 为什么纯规则引擎答不了（C 组，必须说明 ✗）

```
★ 我们的规则引擎的输出是【结构化事实】✗：
   · 关系（月支冲太岁 · 财星被夺 · 官星被化 …）
   · 结构病（被合/被冲/被化/被夺/深藏/孤立）

   · "此命出生家境如何？" → A 富裕 / B 贫穷 / C 父从商母是村干部 / D 父母当官
   · "婚姻如何？" → A 一婚 / B 二婚 / C 一生未嫁 / D 夫早亡
→ ★★★★★ 【粒度不匹配】✗ —— 规则引擎不知道"二婚"✗ 它只知道"夫妻宫被冲"✗
→ ★★★★ 所以要答题，必须【把结构化事实映射到选项】✗ —— 那需要 AI ✗ 或人工规则 ✗

★★★ 结论：
   · C 组（纯规则引擎）【不可行 ✗】→ 请在回执里【说明这一点 ✗ 并给出证据】✓
     （例如：跑几个命主，列出我们输出的事实，说明为什么它们无法直接选 A/B/C/D ✓）
   · ★★★★ 而【这不削弱本任务的价值】✗ ——
     因为 B 组测的正是【规则事实 ＋ AI 能否优于裸 AI】✓
     —— 那才是【我们产品的真实价值主张】✓
```
