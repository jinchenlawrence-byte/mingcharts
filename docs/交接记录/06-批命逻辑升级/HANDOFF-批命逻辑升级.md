# 二、回归用例（★ 验收的试金石）

**辛未 壬辰 壬子 壬寅，男。**

- 日主壬水，三壬透干 + 日坐羊刃 + 年干辛印 + 辰水库 → **身旺，比劫林立**
- 财星（火）：寅中丙、未中丁，**全藏不透**
- 官杀（土）：未、辰，**藏而不透**
- 食伤（木）：寅中甲，**藏而不透**
- 天干：辛(印)、壬、壬、壬 —— **天干全是印比，喜用无一透干**

**己丑大运（23–32 岁）**：己土正官、丑土湿土。

**旧逻辑判定**：己=土(喜) 丑=土(喜) → `good=2` → **「大吉」** ❌

**正确判定（新逻辑必须达成的结论）**：

> 己丑运干己土正官（喜）**透干，但被年干辛金正印化泄**（官生印、印生身），
> 官星"有名无权"；运支丑为湿土，**内藏辛金癸水两个忌神**，制身之力不纯，
> 且**丑冲年支未**，官星动荡；
> 更关键的是**命局财星深藏不透、比劫林立**——此十年财星一透即被比劫所夺，
> 求财费力、易破耗。
>
> **综合：事业名分「平」、财运「滞」。宜守不宜攻，忌一切杠杆投机。**
> **绝不可判「大吉」。**

# 三、改法（四层）

## 3.1 废除单一总分标签 → 分维度

大运/流年不再输出一个「大吉/大凶」，改为**四个维度各自给倾向**：

```
事业 career   /  财运 wealth   /  健康 health   /  六亲 relation
每维倾向 ∈ { 吉, 平, 滞 }，各配一句人话 note
```

数据结构建议（替代现有 tag/note）：

```ts
interface LuckAssessment {
  ganShiShen: string            // 运干十神
  zhiShiShen: string            // 运支十神
  validity: {
    ganHe: boolean              // 运干是否被原局天干五合（如丁壬合）
    zhiChong: boolean           // 运支是否冲原局（子午/丑未/寅申…）
    zhiHe: boolean              // 运支是否被合
    yongHua: boolean            // 喜用是否被化（官印相生 → 官被印化）
    biJieDuoCai: boolean        // 比劫夺财
    caiXingShenCang: boolean    // 财星深藏不透
    guShaGuLi: boolean          // 官杀孤立无财生 / 食伤无力
  }
  domains: Record<'career'|'wealth'|'health'|'relation', { tendency: '吉'|'平'|'滞', note: string }>
}
```

## 3.2 加「有效性四问」（规则引擎的核心新增）

对每个"喜用"，必须回答四问，任一为否则降级：

1. **透没透？** —— 藏干不算数
2. **被合/被冲/被化没？** ——
   - 官杀被印化（原局印透干 + 大运官透）→ 官失效，名多实少
   - 财星被比劫争合/夺（比劫 ≥2 且财透）→ 破财
   - 运支冲原局 → 动荡
3. **有根没？** —— 地支无同类为无根
4. **孤不孤？** —— 官无财生、财无食伤护、食伤无财泄 → 孤立，成色打折

**已识别的五种结构病（必须显式识别并写进 note）**：

| 结构病 | 识别条件（示意） | 文案 |
|---|---|---|
| 官印相生（官被化） | 身旺 + 印透干 + 运见官杀 | 官气被印化，名多实少 |
| 比劫夺财 | 比劫 ≥2 + 财透而无官制 | 财来即被劫，求财易破，忌投机合伙 |
| 财星深藏 | 财只在藏干不透 | 财藏不发，求财费力 |
| 食伤势孤 | 食伤只 1 个且被旺水包围 | 才华难施展，水多木漂 |
| 喜用不纯 | 运支藏干含忌神 | 喜中带忌，力度打折 |

## 3.3 措辞规范

- ❌ 删除「大吉：可主动进取、把握良机」「突破性进展」这类**绝对化、鼓励进攻**的措辞
- ✅ 改为**具体、可操作、留余地**：点名"哪一柱、哪个神、被谁化/冲/夺"，落到"宜守/忌投机/重积累"

## 3.4 AI prompt 同步（`src/lib/aiAnalysis.ts`）

- 大运段要求 AI：**不得输出"大吉/大凶"绝对标签**；必须**分维度 + 点明有效性**（被合/被冲/被化/被夺）；措辞留余地
- 流年/流月同理，且**流月不得再给"大吉/吉"标签**（月度吉凶本就无凭，降为"较宜/一般/宜慎"）

# 七、一句话

> **现在的吉凶 = 数五行个数；要改成 = 判喜用是否"有情有力"。**
>
> 用神到位 ≠ 用神有效。己丑的土是"到了位"，但被印化、被忌神稀释、被冲——
> 一个"失效的喜用"，配一个"大吉"标签，就是把人往坑里指。
>
> **改完后，回归用例那副盘必须显示"财运滞、宜守、忌杠杆投机"，而不是"大吉"。**
