# 二、❌ 主要问题：财运维度失去区分度

## 2.1 实测（9 步大运）

我另写脚本对全部大运跑了一遍：

```
大运总数: 9 | 带财星大运: 2 → 丁亥、丙戌

财运 note 去重后仅 2 种文本（差别只在末尾一句"比劫再临"）:
   [6 步共用] 比劫2重林立而财星深藏不透，财来即被劫夺：求财费力…
   [3 步共用] …（同上）；本运比劫再临，破耗之险更甚…

带财星 vs 无财星 的财运判定:
   带财: 丁亥【滞】 丙戌【滞】
   无财: 辛卯【滞】 庚寅【滞】 己丑【滞】 戊子【滞】 乙酉【滞】 甲申【滞】 癸未【滞】

四维度各步区分度（去重文本数/总步数）:
   career    5/9
   wealth    2/9   ← 且 tendency 9/9 全为「滞」
   health    2/9   （设计即为二值，正常）
   relation  2/9   （同上）
```

**丁亥（正财透干）、丙戌（偏财透干）这两步财运最强的运，与一步财星都不来的运，判定完全相同。**

## 2.2 根因

`src/lib/analysis.ts` 第 809–818 行（`buildDomains`）：

```ts
// 财运：命局若比劫林立 + 财星深藏，则任何大运求财皆费力，比劫运尤忌   ← 注释已自承
const biJie = biJieCount(chart)                  // ← 纯原局
const chartCaiShenCang = godOnlyCang(chart, ['正财','偏财'])   // ← 纯原局
if (v.biJieDuoCai || (biJie >= 2 && chartCaiShenCang)) {       // ← 后半段对全部大运恒真
  wealth = { tendency: '滞', note: '…求财费力…' }
} else if (v.caiXingShenCang) { … }
  else if (isCai) { … }                                          // ← 处理"大运带财"的分支
```

**`biJieCount(chart)` 与 `godOnlyCang(chart,...)` 都只读原局、不看大运**，
所以 `(biJie >= 2 && chartCaiShenCang)` 对这副盘的**每一步大运恒真**。

**后果**：第 821 行那个专门处理「大运带财」的 `else if (isCai)` 分支，**对本盘永远不可达**。
你在 `analyzeValidity` 里做对的大运门控，在下游被这个原局兜底条件**短路了**。

## 2.3 为什么这是问题

**这是原问题倒过来的那一面：**

| | 表现 | 性质 |
|---|---|---|
| 改之前 | 把该守的十年说成「大吉、积极进取」 | **过度乐观** |
| 改之后 | 从 3 岁到 83 岁全说「求财费力」 | **过度宿命** |

两者都是**给用户错误信息**——而用户明确说过："我不想做一个给别人提供错误信息的工具。"

**而且这张盘里这两个运真的不一样：**

- **丁亥**：正财透干，是「财现」之运——虽丁壬合、坐亥比肩（守不住），但**机会出现了**
- **辛卯**：财不现，只能靠伤官间接生财

「财来了但守不住」与「财根本没来」，**感受和应对是两回事**。
全判「滞」，等于告诉用户"你这辈子没财路"。

## 2.4 建议改法

**原则：原局特征应在「命局总论」说一次；大运维度只讲该运带来的变化。**

| 大运类型 | 财运倾向 | 措辞方向 |
|---|---|---|
| 无财星 | 【滞】 | 求财费力，宜凭专业积累 |
| **财星透干** | **【平】** | **财现但比劫夺之——进财机会与破耗并存，宜守不宜投** |
| 比劫运 | 【滞】 | 破耗之险更甚 |

代码上只需调整第 814 行的条件优先级：**先判「大运是否带财」，再叠加原局特征**，
而不是让原局条件无条件抢先。

**建议删除或改名为 `.ts`。**

## 3.2 「比劫2重」计数偏低

```ts
function biJieCount(chart) {
  return stemGans(chart).filter(g => ['比肩','劫财'].includes(SHI_SHEN[dm][g])).length
}   // ← stemGans 只取【天干】
```

只数天干的比肩（月壬、时壬 = **2**），**漏掉地支的劫财**（日支子 = 癸水）。

**实际比劫 = 2 天干比肩 + 1 地支劫财 = 3。**

这副盘共 **4 个水**（3 壬 + 子），说「2 重林立」**弱化了严重程度**。
建议纳入地支本气（或至少地支藏干中的比劫）。
