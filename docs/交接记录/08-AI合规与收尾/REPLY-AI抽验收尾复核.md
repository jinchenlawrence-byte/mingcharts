# 一、✅ 批准判据偏离：归属断言 **优于** 我的「邻近否定」

## 1.1 我的规格确实不够

我在任务书 §1.3 写了「正则已实测 10/10，直接用」。
**但那 10 个用例是我自己造的，全都是"否定 vs 肯定"两类 —— 我漏了第三类。**

你的实测证据：

```
「三者依据等级不同：干支生克为典籍所重，纳音为唐宋古法之遗，生肖则为民间俗论」
  我的规格 → 误报 FAIL ✗
  归属断言 → INFO ✓
```

**这句话不但合规，而且是依据分级的"标准写法"。**

## 1.2 你找出了我漏掉的那一类

我的抽象是「**否定词与典籍的距离**」——处理的是"肯定/否定"。
你的抽象是「**是否存在归属断言**」——多覆盖了一类：**"只是并列分级，根本不存在归属断言"**。

**你的抽象维度更对。** 因为我们要判的本质是：

> **「有没有把 A 说成属于 B」** —— 那就该直接检测"归属"这个语义关系，
> 而不是退而求其次检测"两个词挨得近不近 + 有没有否定"。

**我的方案是在做近似，你做的是本义。**

## 1.3 而且你的偏离过程完全正确

你没有直接推翻我的规格，而是：
1. **先按任务书实现了第一版**（否定词紧邻 ±3 字）
2. **实抽中拿到反例**（合婚 #3 的并列分级句）
3. **才升级判据**
4. **并在回传里明确请我复核认可**

**这正是该有的做法。** 如果一上来就"我觉得你写的不对，我改了"，
那就变成两个规格方各执一词。**先按规格做、用证据说话、再请批准** —— 这是对的。

## 1.4 用例 12 尤其好

```js
['fail', '生肖合婚与典籍所载一致，不仅如此，年支亦无冲克']
```

**用「不仅」这个递进词试探"否定词是否被过度放宽"。**
这是我任务书 §五 那句「不仅要验不再误报，还必须验真违规仍抓得住」的**具体落实** ——
而且选词很刁：`不仅` 含 `不`，正是最容易被否定逻辑误当"否定"的情形。

# 三、✅ 认可产品安全网的两个手段

## 3.1 「不必 → 无须」等价替换

你的论证：**语义不变，非篡改观点**，且**打印替换处数**。

**我认可。** 理由：

- 「不必介怀」→「无须介怀」**语义完全等价**，不是掩盖违规，是**措辞等价替换**
- 且**不是静默**（打印处数）
- 这与"把违规内容过滤掉"有本质区别 —— 后者会**掩盖模型的问题**，前者只是换一个同义词

## 3.2 「重试一次 → 仍违规回退规则版」

**我认可，而且回退目标选得对。**

我任务书 §2.4 写过：

> ⚠️ **不要用后置过滤代替 prompt 修正。**

你的设计是：**主手段仍是 prompt → 重试是二次机会 → 回退到"规则版文案"**。

**关键是回退目标是规则版，不是"删改后的 AI 输出"。** 后者会掩盖违规；
前者是**诚实地降级到人造内容**。这个区别很重要，你选对了。

## 3.3 判据收为单一事实源（`ai-check.ts`）

> "杜绝尺子和被量的东西各写一份、逐渐漂移"

**这个做法我特别赞赏** —— 它把"产品防线"和"验收判据"绑成同一份代码，
**从结构上消除了"测试过了但产品没接"的可能**。

这和我们前几轮反复吃的亏（改了核心函数但某个入口没接）是同一类问题的**正面解法**。

## 3.4 紫微事实集：你做得比我要求的更严

我任务书说"两个方向都行（补 prompt 或收窄事实集）"。
**你选了 (a) 补 prompt，同时把事实集严格收窄为"7 宫干支 + 3 运限干支"，与 prompt 逐字对齐**
（并说明 palaceBlock 只渲染 7 宫，另 5 宫 prompt 根本不出现）。

**比我要求的更精确。** 我原话只说"事实集 ⊆ prompt"，
你还额外确认了"不存在事实集宽于 prompt 的情况"。
