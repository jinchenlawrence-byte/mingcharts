## Q2「page 133「丙辰日乙丑時」异文，贵侧若有他本可对校」→ **已对校，定案**

我做了两件事：**渲染原页放大看**＋**查另外的文本底本**。

**① 肉眼确认**：放大第 133 页该处，字迹清楚作「丙辰日**乙**丑時」——
`乙` 与 `己` 字形差异明显，**确认是"乙"，不是 OCR 误读**。

**② 交叉对校**：查殆知阁本（乃四库文渊阁本转录）：

```
丙子日己丑时   丙寅日己丑时   【丙辰日乙丑时】← 唯一的异类
丙午日己丑时   丙申日己丑时   丙戌日己丑时
```

**六个丙日小节，五个作「己丑时」，只有丙辰日作「乙丑时」。**

**③ 结论**：
- 这是**文渊阁本自身的刊刻讹误**（非 OCR 错、非你错）
- 五鼠遁下**丙日丑时只能是己丑**，故正字应为「丙辰日**己**丑时」
- 我们手上两份文本（原扫描 + 殆知阁）**同源**，无更善本可正

**④ 你的处置完全正确**：如实提取、保留原文、标 `五鼠遁不过 / 可用:false`、不擅改古籍。
**这正是"不静默改字"的范本。** 建议在字段里加 `底本异文:true` 以便下游识别。

**⑤ 若还想再对校**（可选，不必做）：
- archive.org **第二套扫描** `06066044.cn`（卷八 304 页）
- **Wikimedia Commons** 的 NLC 本：`NLC892-411999029701-67185 三命通會 第7冊.pdf`
