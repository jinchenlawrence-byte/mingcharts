# 二、核心发现：为什么完整四柱只有 100 条（而非数百）

## 2.1 命例表两种形态

| 形态 | 刻写 | 可定柱 | 数量 |
|---|---|---|---|
| **行内型** | 同一文本行「年干支+月干支」紧密成对 | 完整四柱 | **100** |
| **分列型** | 命例分列竖排，每条「年干支+人物+官衔」，**月柱省略** | 年+日+时 | **6290** |

日柱、时柱对两者都由所属小节标题「X日Y時」给定——体例如此，五鼠遁可证伪，属读表非编造。

## 2.2 跨列补月柱被证伪（关键）

我实现了跨列配对（左列纯干支按 y 对齐当月柱），初版得到 874–1568 条"看似完整"的命例，历法合法率 >99%。
但回图核查 **page 13**：

```
真布局：  「乙亥 陳瑞 尚書」属【甲戌日】小节；其左(x≈421)的「丁亥」属【甲申日】小节
错配结果：年乙亥 月丁亥 日甲申 时乙丑 —— 五虎遁✓ 五鼠遁✓，但人物、日柱全错
```

即：**历法双通过无法证明跨列归属正确**——古籍相邻各列多为独立年柱，"真月柱"与"邻列年柱"不可区分。
为守"不得编造"红线，**撤销全部跨列配对**，分列型 6290 条一律标"缺月柱"。

## 2.3 这不是算法没做对，是源数据只给了这些

唯一零歧义的月柱来源是行内型（同文本行两干支）。凡月柱有据者双通过率 **98/100 = 98.0%**，
2 条例外是古籍自身异文（§三），非拼装问题——已满足"接近 100%"的验收口径。
