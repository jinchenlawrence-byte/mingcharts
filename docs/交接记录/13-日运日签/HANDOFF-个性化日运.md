# 一、定位与红线

## 1.1 与通用日签的分工

```
通用日签（免费）：60 甲子 → 一句「今日一省」，与你是谁无关
个性化日运（订阅）：今日干支 × 你的命局 → 一句「对【你】而言的一省」
```

**★ 一句话定位**：**日签是历法的，日运是你的。**

## 1.2 硬红线（沿用日签，并加两条）

| # | 禁止 |
|---|---|
| 1 | **不判吉凶** —— 不出现「宜做某事/忌做某事」的具体事项判决 |
| 2 | **不绝对断言** —— 禁用：大吉 大凶 必定 务必 必然 一定会 注定 **必** |
| 3 | **不恐吓** —— 禁用：凶 劫 灾 破财 血光 小人 犯太岁 化解 开运 |
| 4 | **不替用户决策** —— 不出现「今天适合签约／不宜出行」 |
| 5 | **不引导消费** |
| 6 | **不做成瘾式机制** |
| 7 | ★ **十神与关系只作"视角"，不作"判决"** —— 不得写「七杀临日，诸事不顺」这类句式 |
| 8 | ★ **不得把关系写成宿命** —— 「相冲」只能写成「有推动也有拉扯」，不得写成「必生变故」 |
| 9 | ★★ **刑／害两组必须"可自省"，不可"可害怕"** —— 见 §1.4（本批最大风险） |

## 1.4 ★★ 引入「害」之后必须同时做的四件事（**§1.3 的配套，不是可选项**）

> **风险来源**：「刑」「害」是唯二**纯负语义**的关系轴。
> 它们各占 30 条（10 十神 × 3 变体），**若写成"判定"，就会有 60 条在结构上偏向负面** ✗
> **下面四条就是把它压回去的措施。**

**① 定调表把「害」写成【可自省的视角】，不是威胁**（见 §3.3）
　　→ 「害」= **不显的消耗**；视角是「留意那些没明说、却一直在耗你的事」✓ 不是「有灾」✗

**② UI 里古典名必须紧跟白话注解**
```

今日日支与你日支相刑（古法名；指纠葛反复，非吉凶）
```
　　**讲依据 ≠ 用吓人的词** ✓ **古典名照给（诚实），注解紧跟（不吓人）** ✓

**③ ★ 新增「负面词密度」断言**（禁词表防不住"整句基调"，密度能）
```

  消耗 消磨 耗损 磨损 纠缠 拉扯 内耗 压抑 憋闷 亏 损失 反复
★ 一条里命中 ≥2 个 → 翻红

**④ 高危组从 6 组扩到 10 组**：（七杀/伤官/劫财/正官/偏印）×（刑/害）

#### ★ 巳申的**古籍原文**（已核实，务必照抄进代码注释与披露文案）

```
【隋·萧吉《五行大义》】——已知最早对"巳申既合又刑"做系统思辩的著作
  「六合是吉，而巳申相克者何。答曰：金带水生火中，火为金鬼，水为火鬼，
    金共水生火中，则是鬼母子身。申是金位，兼复怀水，巳是火位，复有生金，
    还相雠，故以为刑也。」

【晋·郭璞《郭氏元经》】——更简明的同源解释（"无恩"得名之由）
  「巳刑申者，巳属火，申属金，巳又能克金，是所生之处反相刑而无恩，故曰无恩刑。」
       → 申金【生于巳】（金长生在巳），却被巳火所克
       → 「所生之处反相刑」→ 恩中生怨，故名【无恩之刑】
```

**★★★ 而古法对"哪个优先"的立场是 —— 【不分先后，同时存在】：**

```
· 巳申相合 ＝ 天理（七月日月会于鹑尾之次，斗建在申，故申与巳合）
· 巳申相克 ＝ 地理（巳火克申金）
· 巳申相刑 ＝ 人理（母子甥舅，"无恩"二字即指此）
→ 【天地人三者同时存在，不必分先后】
```

**★ 古籍自己的一句话，正好是我们的立场依据：**

> **「相合不一定为喜，相克也不一定为忧。」**
> —— **这正是本产品「不判吉凶」的古典依据** ✓ 请写进代码注释。

### 十神 → 自省视角（**不是吉凶**）

### 关系 → 境遇质感（★ 后两行是本批风险所在，写法已定死）

| 关系 | 质感 | 必须避免的写法 |
|---|---|---|
| **冲** | 有推动，也有拉扯 | ✗「相冲，必有变故」——宿命化 |
| **合** | 牵合、亲近、顺 | ✗「六合，诸事大吉」——吉凶化 |
| **刑** | ★ **纠葛、反复；多发生在明面上** → 宜把话说清 | ✗「相刑，谨防是非」——恐吓 |
| **害** | ★ **不显的消耗；多发生在没明说的地方** → 宜留意那些一直没被说出口的小事 | ✗「相害，小心暗算」——恐吓 |
| **同** | 同类叠加、加重 | ✗「伏吟，灾祸重来」——恐吓 |
| **无** | 平顺，无特别牵动 | ✗ 写成"什么都不会发生"的空话 |

**★★ 刑与害必须可辨**：

```
刑 = 明面上的摩擦 → 落点是「把话说开」
害 = 暗处的磨损   → 落点是「留意没被说出的消耗」
