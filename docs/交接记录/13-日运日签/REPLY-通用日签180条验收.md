## 2.2 为什么这值得返修

```
日签是【每天读】的产品；
而变体是【每 60 天】才轮换一次（floor(dayNumber/60)%3）。
→ 用户会【连续 60 天】看到「心在…／心像…／心里…」开头的句子。
→ 一定会察觉。
```

**变体2 的「心绪型」定位没错**（心是主题词），**问题在「每条都以心字起句」这个句式定式** ✗

## 2.3 ★ 而正确写法**已经在你自己的稿子里**

```
乙丑[2]「把未发的情绪先收好，沉住气慢慢等它松。」   ← 以【情境】起句，心不出现在开头 ✓
戊辰[2]「将变未变之际，心先沉下来，听动静。」       ← 心在【后半句】✓
```

**→ 这两种写法就是解** ✓
