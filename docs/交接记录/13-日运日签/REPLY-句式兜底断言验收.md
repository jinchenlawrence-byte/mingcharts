# 二、#11 的实现我方认可

```js
const MAX_PREFIX = 6
for (let vi = 0; vi < 3; vi++) {
  // 统计该变体 60 条的「前两字」频次
  const [topP, topN] = [...freq.entries()].sort((a, b) => b[1] - a[1])[0]
  if (topN > MAX_PREFIX) {
    fail(`变体[${vi}] 前两字「${topP}」×${topN}/60（> ${MAX_PREFIX}）：${keys.join(' ')}`)
  }
}
```

**三点做得好**：

1. **量的是属性**（前两字集中度），**不是某个具体词** → 能覆盖**未来任何新出现的定式** ✓
2. **逐变体分别算** ✓ 三个变体各 60 条，语域不同，混算会失真 ✓
3. **报错列出全部命中键** ✓ 排查可用 ✓

**层次也对**：#10 三条**词级盯防**（盯已知重点）＋ #11 **属性兜底**（防未知定式）✓

```
★ 「确认注入有效」必须是【肯定性证据】：打出改变后的实际值并与预期比对。
```
