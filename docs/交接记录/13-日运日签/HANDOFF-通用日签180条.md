# 一、定位与红线

## 1.1 事实前提

命理影响力层级：**大运 > 流年 > 流月 > 流日** —— **流日是最弱、最无凭的一层。**

而我们已立的规矩是**流月都不能说「大吉」**。**所以日签的措辞必须比流月更克制。**

## 1.2 硬红线（违反即返工）

| # | 禁止 |
|---|---|
| 1 | **不做吉凶判断** —— 不出现「宜做什么事」「忌做什么事」的**具体事项判决** |
| 2 | **不给绝对断言** —— 禁用：大吉 大凶 必定 务必 必然 一定会 注定 **必** |
| 3 | **不恐吓** —— 禁用：凶 劫 灾 破财 血光 小人 犯太岁 化解 开运 |
| 4 | **不做决策指导** —— 不出现「今天适合签约／不宜出行」这类**替代用户决策**的句子 |
| 5 | **不引导消费** —— 不出现「请购」「化解」「补运」 |
| 6 | **不做成瘾式机制** —— 不做连续签到奖励、断签提醒 |

## 1.3 每条的句式

```
一条日签 = 【当日干支的意象】 → 【一句自省／提醒】
           ↑ 呼应 §三 定调表          ↑ 轻，不判吉凶
```

**正例（请照此风格）**：

```
甲子：水润初木，根气方生 —— 起意容易，成事需时日。
丙午：日光当顶，明极而燥 —— 势头正盛，也宜留一分余地。
庚申：金气肃降，锋刃在秋 —— 该收的收，该断的断。
癸亥：雨入深潭，静而不显 —— 不妨把话留在心里过一夜。
乙卯：蔓草就风，柔而不断 —— 借势比用力省。
```

**反例（一律返工）**：

```
✗ 今日大吉，诸事顺遂。            ← 绝对断言 ＋ 禁用词
✗ 务必在午后签约，否则必败。        ← 命令 ＋ 恐吓
✗ 今日凶，忌出行，谨防破财。        ← 恐吓 ＋ 决策指导
✗ 今日财星高照，投资必有所获。      ← 决策指导 ＋ 断言
```

# 二、数据与选片逻辑

## 2.1 落点

**新建** `src/data/daily-signs.ts`：

```ts
/** 通用日签：60 甲子 × 3 变体 = 180 条。
 *  ★ 静态资产 —— 构建期内联，运行时零 IO、零 AI 调用（设计稿 §2.4）。 */
export const DAILY_SIGNS: Record<string, readonly [string, string, string]> = {
  甲子: ['…', '…', '…'],
  乙丑: ['…', '…', '…'],
  // …60 个甲子，每项恰 3 条
}
```

**要求**：

- **恰 60 个键**，且键必须与 `daily.ts` 的六十甲子表**逐一对应**（同一套六十甲子）
- 每项**恰 3 条**，**3 条互不相同**
- 每条**长度 12–28 字**（含标点）

> **★ 前置改动**：`src/lib/daily.ts` 第 71 行的 `const JIAZI = [` **当前未导出**，
> 断言无法引用。**请改为 `export const JIAZI = [`**（只加 `export`，内容一个字不动）。
> 理由：它是六十甲子的事实表，断言须以它为唯一来源，**不得在测试里另抄一份**（§8.5.1）。

## 2.2 ★ 选片逻辑（放进 `src/lib/daily.ts`）

**两个要求**：

```
① 确定性：同一天对所有用户给同一条（不得随机、不得随时刷新变化）
② 跨周期轮换：每过一个 60 甲子周期，换用下一个变体
   —— 否则同一个人在第 2、3 个周期会看到完全重复的 60 条
```

**建议实现**：

```ts
/**
 * 取当日日签。
 * @param ganZhi   当日日干支（来自 liuRiOf）
 * @param dayNumber 自固定纪元起的天数（如 Math.floor(Date.UTC(y,m-1,d)/86400000)）
 * ★ 确定性：只依赖这两个入参，不依赖当前时刻／随机数
 * ★ 轮换：变体序号 = floor(dayNumber / 60) % 3
 */
export function pickDailySign(ganZhi: string, dayNumber: number): string {
  const trio = DAILY_SIGNS[ganZhi]
  if (!trio) throw new Error(`日签缺该甲子：${ganZhi}`)   // 不静默兜底
  return trio[Math.floor(dayNumber / 60) % 3]
}
```

> **★ 缺键必须抛错，不许回退** —— 与 `liuRiOf`、`jiaziIndex` 同一原则（§8.5.1）。

## 2.3 固定免责说明（**不是每条都写，而是卡片固定一行**）

```
日签取传统历法意象，属民俗文化，非预测。
```

**理由**：单条 12–28 字，塞不下"依据分级"；**但依据披露不能省** ✓
→ 用**卡片固定说明**满足披露要求 ✓ 这也与 `ai-check.ts` 的依据分级精神一致 ✓

# 三、★ 文案生成规范（180 条的"准绳"）

## 3.1 定调表 · 10 天干 = **态势**

| 天干 | 态势意象 | 可用词向 |
|---|---|---|
| **甲** | 生发、挺拔、向上 —— 如乔木初展 | 起意、谋始、条达 |
| **乙** | 柔韧、攀附、缠绕 —— 如藤蔓就势 | 借力、迂回、柔进 |
| **丙** | 显扬、炽烈、外向 —— 如日光普照 | 示人、显扬、昭明 |
| **丁** | 温养、细腻、内明 —— 如灯烛照微 | 细节、温养、内照 |
| **戊** | 厚重、承载、稳守 —— 如高岗厚土 | 持重、承载、守成 |
| **己** | 包容、卑湿、化育 —— 如田园沃土 | 容纳、含藏、化育 |
| **庚** | 刚断、肃杀、更革 —— 如刀斧裁物 | 决断、裁减、更张 |
| **辛** | 精微、饰美、收敛 —— 如珠玉待琢 | 打磨、精微、修饰 |
| **壬** | 流动、奔涌、通达 —— 如江河赴海 | 变通、通达、奔流 |
| **癸** | 潜润、涵蓄、幽微 —— 如雨露入土 | 静养、涵蓄、幽微 |

## 3.2 定调表 · 12 地支 = **境遇**

| 地支 | 境遇意象 |
|---|---|
| **子** | 潜藏，萌动于暗 |
| **丑** | 蓄积，凝结未发 |
| **寅** | 萌发，破土而动 |
| **卯** | 舒展，条达外放 |
| **辰** | 蓄势，将变未变 |
| **巳** | 炽盛，明而渐极 |
| **午** | 鼎盛，极而将返 |
| **未** | 和缓，味厚而缓 |
| **申** | 收敛，肃降而整 |
| **酉** | 成熟，精纯而定 |
| **戌** | 收藏，归拢将闭 |
| **亥** | 归藏，静极待生 |

**★ 组合方式**：每条的意象应能同时呼应**天干的态势**与**地支的境遇** ✓
（例：`甲子` = 甲（生发）＋ 子（潜藏）→「水润初木，根气方生」✓ 两条都呼应到了）

## 3.3 ★ 3 个变体的角度分工（**必须分工，不能只换措辞**）

| 变体 | 角度 | 落点 |
|---|---|---|
| **第 1 条** | **意象型** | 以当日干支的自然物象起兴 → 落到一句自省 |
| **第 2 条** | **处事型** | 以当日态势给一条**轻量处事提醒**（不给具体事项判决） |
| **第 3 条** | **心绪型** | 以当日境遇点出一句**内在观照** |

**反例**：3 条只是把同一意思换了说法 → **不合格**（要求角度不同，不是同义改写）

## 3.4 文风规范

```
· 长度 12–28 字（含标点）
· 常用轻词：宜、可、不妨、不妨就、留一分、借势、缓一缓、过一夜、看得清
· 语气：提醒 / 自省，不是判决、不是命令
· 不出现第二人称"你"以外的称呼；可用"人""心""事"作泛指
· 不用问号、不用感叹号连用
· 不堆四个字的成语串（读起来像签文，不像提醒）
· ★ 每条都应能读出"为什么"（呼应定调表），但不要求出现干支术语
```
