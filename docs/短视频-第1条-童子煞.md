# 第 1 条短视频素材包：童子煞（C 端版 · 面向命理爱好者）

> **目标人群改了**：不是命理师，是**被说过「你是童子命」的普通人**。
> 素材：`public/video/tongzi-1.png` ~ `tongzi-4.png`（1080×1920）
> 平台：**YouTube Shorts**（唯一能放链接 + 有长尾搜索）
>
> ★ 为什么改：原版第 1 帧写「客戶問你」，那是把观众当成命理师——
>   B 端内容该发在私域圈子（FB 社团 / LINE 群 / 论坛），不适合公域视频。
>   视频是「推荐给陌生人看」，所以第一句必须是**关于观众自己**的。

---

## 一、60 秒脚本（照念即可）

| 段 | 画面 | 口播 | 时长 |
|---|---|---|---|
| 1 | 有人跟你說你是童子命？ | 「有人跟你說，你是童子命？先別慌，這條不用怕。」 | 0–10s |
| 2 | 口訣與查法 | 「口訣是：春秋寅子貴，冬夏卯未辰；金木馬卯合，水火雞犬多，土命逢辰巳。對上了，也先別緊張。」 | 10–26s |
| 3 | 超過一半的人都對得上 | 「因為超過一半的人都對得上。而子平正典——《淵海子平》《三命通會》——根本不把童子煞當判據。它是民俗傳說，不是命理斷語。一個半數人都有的標記，區分不了任何人。」 | 26–48s |
| 4 | 查得到，但別讓它決定你 | 「所以：查得到，但別讓它決定你。沒必要為這個標籤花錢化解。想自己查，連結在描述裡。」 | 48–60s |

**第 1 句必须在 3 秒内说完**，而且要像在跟他说话，不是在讲课。

## 二、标题（选一个，都指向「观众自己」）

```
有人說你是童子命？先對一次口訣，再決定要不要怕
童子命是真的嗎？超過一半的人都對得上
被說童子命要花錢化解？先看這三個字怎麼查
```

**别用**：「童子煞查法详解」—— 那是 B 端/搜索语，不是视频语。

## 四、发布后只看两个数

```
① 完播率      ≥40%  → 选题与开头成立，做第 2 条
              20-40% → 开头要改（前三秒换一句），内容留着
              <20%  → 这个题目不适合视频，换題

② 外部链接点击  描述里两个链接有没有人点
                （YouTube 后台 · 触达 · 外部链接）
```

**7 天内不到 1000 播放**：冷启动没过，**先换标题与首帧重试同一条内容**，别急着换题。

## 五、这版和上一版的差别（记住这个原则）

| | B 端版（错放） | C 端版（现在） |
|---|---|---|
| 第一句 | 客戶問你：我是不是童子命？ | **有人跟你說，你是童子命？** |
| 立场落点 | 我的做法（查得到但不下断语） | **別讓它決定你、別花錢化解** |
| 结尾动作 | 引导命书/会员 | **免费自己查（链接在描述）** |
| 适合渠道 | FB 社团、LINE 群、论坛 | **YouTube、小红书、TikTok** |

**同一个知识，两种说法。** 以后每条视频都问一句：**这句话是对观众说的，还是对同行说的？**

