# 一、发帖文案（配卡图，一周一张）

## 01 童子煞

```
【神煞速查 01】童子煞

口訣：春秋寅子貴，冬夏卯未辰；金木馬卯合，水火雞犬多，土命逢辰巳。

這條最要緊的不是怎麼查，是查完之後怎麼講：

子平正典（《淵海子平》《三命通會》體系）並不以童子煞為判據。
它是民俗傳說，不是命理斷語。
健康看五行旺衰，婚姻看夫妻宮與配偶星。

换句话说 —— 這張卡是拿來安客戶的心，不是拿來嚇客戶的。
```

## 02 天乙貴人

```
【神煞速查 02】天乙貴人

口訣：甲戊庚牛羊，乙己鼠猴鄉，丙丁豬雞位，壬癸兔蛇藏，六辛逢虎馬。

★ 這句最要緊：
貴人須與喜用並見，方有大力；若貴人坐忌神，助力有限。
不可見貴人即言吉 —— 一切以生克格局為準。

看盤看到貴人就說「你有貴人、會有人幫」，是最容易講錯的一句。
```

## 03 空亡

```
【神煞速查 03】空亡

甲子旬中戌亥空，甲戌旬中申酉空，甲申旬中午未空，
甲午旬中辰巳空，甲辰旬中寅卯空，甲寅旬中子丑空。

★ 空亡不等於凶：
吉神空亡，吉力落空；凶神空亡，凶性反減。
七殺空亡反減壓力，傷官空亡反減是非。

以日柱定旬，再看四柱地支落在哪兩支。
```

## 04 羊刃

```
【神煞速查 04】羊刃

甲刃在卯，丙刃在午，戊刃在午，庚刃在酉，壬刃在子。
即陽干的帝旺之位，陰干不論。

★ 羊刃的雙面性：
身弱得刃幫身 → 為福；身強刃重無制 → 為患。
喜官殺制刃，古稱「殺刃兩停」，多主掌權之造。

不可單見羊刃即言凶，亦不可見殺刃即言貴。
```

## 05 六秀日

```
【神煞速查 05】六秀日

丙午、丁未、戊子、戊午、己丑、己未 —— 只看日柱，六組之一即是。

古人以日柱干支同氣清純為「秀」，故謂坐下秀氣。
（戊午同時在十靈日之列，兩樣並見屬正常。）

★ 才學之事，看食傷與印星的實態更直接。
六秀添的是「靈秀」的色彩，不是判定。
```

# 二、社团回答范例（这三条决定人家记不记得你）

## 范例 1：有人问「我是不是童子命？好担心」

**核心：先给准确答案，再解除恐惧，最后给出路。不安慰、不吓人。**

```
先別慌，把查法對一次：

民間口訣「春秋寅子貴，冬夏卯未辰；金木馬卯合，水火雞犬多，土命逢辰巳」。
按月支季節：春秋兩季（寅卯辰、申酉戌月）生，日支或時支見寅、子；
冬夏兩季（亥子丑、巳午未月）生，日支或時支見卯、未、辰。

對上了也別緊張 —— 子平正典（《淵海子平》《三命通會》體系）不把童子煞當判據。
它是民俗傳說，所謂「真假童子」「輕重」各派講法都不一樣，沒有統一典籍口徑。

真正要看的：健康看原局五行旺衰與十神配置，婚姻看夫妻宮與配偶星實態。
如果有人拿這個標籤叫你做法事花錢，你可以請他把依據的典籍翻給你看。
```

**为什么这样答有效**：
- 第一段就可核对（不是空话）
- 中间解除恐惧（这正是客户最需要的）
- 最后一句给了客户**拒绝被推销的话术** —— 他会记住是谁教他的

## 范例 2：有人问「空亡是不是不好？我日柱空亡」

**核心：直接纠正误解，并给出「什么时候空亡反而好」。**

```
空亡不是凶，是「落空」。

查法：以日柱定旬 —— 甲子旬戌亥空、甲戌旬申酉空、甲申旬午未空、
甲午旬辰巳空、甲辰旬寅卯空、甲寅旬子丑空。

作用的關鍵是「空掉的是什麼」：
吉神喜神空亡 → 吉力落空，要等歲運填實或沖空才發力；
凶神忌神空亡 → 凶性反減，七殺空亡反而壓力小，傷官空亡反而少是非。

另外要分真假：逢沖、逢合、被填實的是假空，歲運可解；
安靜無氣又遭剋泄的才是真空，力量難復。

所以「我空亡」這四個字本身說明不了任何事。
```

## 范例 3：有人问「天乙贵人到底是牛羊还是虎马？口诀怎么前后矛盾」

**这条是分水岭 —— 答得出来，同行就知道你读过书。**

```
您問到點子上了，這句口訣在傳本上確實有異文。

常見兩種寫法：
一作「甲戊庚牛羊……六辛逢虎馬」，
一作「甲戊兼牛羊……六辛逢馬虎」。
差別在「庚」該歸前句還是後句 —— 庚若已在前句取丑未，後句就不該再出現庚。

實務上的處理原則：以能自洽、不重複計入為準。
所以多數排盤取「甲戊庚見丑未、六辛見寅午」。

但更值得記住的是另一句：
貴人須與喜用並見方有大力，貴人坐忌神助力有限。
口訣的異文不影響實務，因為神煞本來就只是輔助點綴，主體還是五行生克與格局旺衰。
```

**为什么这条最值钱**：它证明你不是背口诀的人，是**读过不同版本、知道分歧在哪**的人。

# 三、使用顺序（别一次全发）

```
第 1 周   发 01 童子煞（立场牌，最容易引起同行共鸣）
第 2 周   发 02 天乙貴人（最常被問，覆盖面最大）
第 3 周   发 03 空亡（纠正常见误解）
第 4 周   发 05 六秀日（GSC 已有真实搜索需求）
         04 羊刃留到第五周（争议大，等前四张积累一点信任再发）

同期每天：在社团答 1 个问题，优先用范例 1 和 3 的写法
```

## 一条判断标准

**如果发了 4 周，有人开始私信问「你這些資料是從哪查的／用什麼工具」——策略成功。**

如果 4 周过去只有点赞、没人问，说明**内容对了但人不对**，
换地方（去 YouTube 评论区、论坛），不要在这条路上加码。
