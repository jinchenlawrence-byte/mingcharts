# 五之二、★ 域名与支持邮箱（**WAFFO 官方口径**）

> 来源：[Support Email Verification](https://docs.waffo.ai/settings/email-verification) ·
> [Domain Verification](https://docs.waffo.ai/settings/domain-verification)

## 5b.1 支持邮箱是什么、做什么用

**它是买家在收据、支付失败通知、客户门户上看到的那个邮箱** —— 客户有问题就发到这里。

**Pancake 会验证它**：往该邮箱发一个 **6 位验证码**，输入后即绑定。
目的官方原话是确认「**the address is reachable and that you control the inbox**」。

## 5b.2 ★ 更正：**Waffo 接受 Gmail**

我此前说"必须品牌域名、不能 gmail" —— **那是 Creem 的要求，不是 Waffo 的**。

**Waffo 官方原文**：

> **"Use an inbox you control. Free providers (Gmail, Outlook, etc.) are accepted**,
> but Pancake recommends an address on the same domain as your product website
> so you can also use the one-click domain fast-path."

**但用 Gmail 有一个代价** —— **失去「一键验证域名」**：

> "If the support email is on a different domain (e.g. `team@gmail.com` while the
> site is `acme.com`), this option is hidden — **use one of the manual methods below**."

## 5b.3 两种方案对比

| | **A. Gmail** | **B. support@你的域名** |
|---|---|---|
| 成本 | ¥0 | 域名钱（~$10/年），**转发免费** |
| 可用性 | 立刻可用 ✓ Waffo 接受 | 需 ~10 分钟配置 |
| **域名验证** | ❗ 需手动：DNS TXT / meta 标签 / `.well-known` 文件 | ✅ **一键验证**（自动匹配） |
| 收据上显示 | `xxx@gmail.com`（稍显业余） | `support@你的域名` ✓ |
| 收信 | ✓ | ✓（转发到你的邮箱） |
| **发信** | ✓ 原生 | ⚠️ 默认回信会显示你的 Gmail；要"以域名身份发"需另配 SMTP |

**★ 我的判断：方案 B 反而更省事。**

因为**你本来就要买域名**（网站必须上线才能过审），
而 **Cloudflare Email Routing 转发是免费的** ——
**增量成本只是 10 分钟配置，却省掉了"手动验证域名"这一步**，还更专业。

## 5b.4 零成本配置路径（方案 B）

```
① 买域名            Cloudflare Registrar（按成本价，无溢价）/ Namecheap / Porkbun
② DNS 托管到        Cloudflare（免费）
③ 开邮件路由        Cloudflare → Email Routing → 自定义地址
                    support@你的域名  →  转发到你的 Gmail       【免费，收信】
④（可选）配发信     用 Resend / Brevo 免费额度 作为 SMTP，
                    加到 Gmail 的「Send mail as」→ 即可「以域名身份发信」
                    （Resend 免费 3000 封/月；Brevo 免费 300 封/天）
⑤ 站内展示          页脚 + /pricing 页 + ToS/隐私页的「联系我们」
```

**⚠️ 注**：**Zoho Mail 免费版已明确不再支持 IMAP/POP/SMTP**，
所以"Zoho 免费版当发信主机"这条路**不通** —— 要用 ④ 里的 Resend/Brevo，
或直接上 Google Workspace（约 $6/月）。

## 5b.5 ★ 但真正的门槛在**前面**：你需要一个域名 + 已上线的站

Waffo 的审核项里，这些是**硬要求**：

```
· Product website URL —— 一个 live、publicly reachable 的页面
· Product is live —— 不能有登录墙、密码、或「coming soon」占位
· Domain verification 是提交 KYB 的【前置】——
  Step 8 (Website URL) 未验证，Submit for review 按钮【保持禁用】
```

**所以真实顺序是**：

```
1. 确定产品名  →  2. 买域名  →  3. 部署上线（Vercel 免费即可，本项目是 Next.js）
     ↓
4. 配域名邮箱（Cloudflare Email Routing，免费）
     ↓
5. 补 /terms /privacy（用 Waffo 模板）
     ↓
6. 站内展示支持邮箱
     ↓
7. Waffo 后台：验证邮箱 → 验证域名 → 提交 KYB
```

**★ 注意第 1 步是个决策** —— **产品名 = 域名**，而且审核项里有「**无商标冲突**」。
**这个必须先定，后面所有事都挂在它上面。**
