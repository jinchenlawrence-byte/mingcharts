# 〇、先说清楚：我们的红线**不是**中国法规带来的

这是最需要纠正的一处前提。逐条追溯每条红线的**真实驱动**：

| 我们的红线 | 真正的驱动 | 转向美国后 |
|---|---|---|
| **不绝对断言**（必/一定/注定） | **FTC 的 deception / substantiation 标准**（判例驱动，比中国更容易被起诉） | **不变，或更严** |
| **不判吉凶**（不说"今日大吉／不宜出行"） | **产品定位**（流日在命理层级最弱）＋ 避免"具体结果"声明 | **不变** |
| **不做投资建议**（财运措辞） | **Waffo 的 licensed-category 限制** ＋ 美国的 investment adviser 法 | **更严** |
| **订阅自动续费条款** | 此前按 Waffo 要求写 | **★★ 美国严得多**（见 §二） |
| **不得是"人的时间"** | **Waffo／卡组织**（全球性规则，非某国法规） | **不变** |
| **免责声明**（非预测／娱乐用途） | **FTC ＋ 应用商店** | **不变，且 App Store 明确要求** |

**★ 结论**：这些规矩里**没有一条是"中国特有的"** ✓
**→ 转向美国不会让它们消失；其中两条反而会更紧。**

| # | 法律要求 | 我方现状 |
|---|---|---|

# 二、★ 那么"更多按古籍来"，正确的形态是什么

## 2.1 ★★ 一句最关键的话

> **按古籍的【方法与条件】，不按古籍的【断语】。**

## 2.2 为什么

古籍里确实有**大量明确吉凶的断语**（「甲子日生人富贵」「七杀无制必主凶夭」…）。
**若为了"更古籍"而放出这类断语，会同时踩三条线**：

```
① FTC 的 deceptive / unsubstantiated claim（美国）
② Waffo／卡组织的 divination 类目限制（见 §三）
③ 我们自己的"不吓人"定位与用户信任
```

**★★ 而真正的古法本来就有分寸** —— 这句是古书自己的话：

> **「相合不一定为喜，相克也不一定为忧。」**

**→ 真正的古法是讲【条件】的，不是讲【断语】的** ✓
**→ 所以"更古籍"的正确做法是：把条件写清楚、把依据给出处，而不是把话说死。**

## 2.3 ★ 我们已经在做的、可以继续加厚的地方（**这些是真资产**）

```
· 术语用古籍原词（十神／三刑／无恩／调候／五鼠遁…）      ✓ 已在做
· 依据给出古籍原文与出处                                ✓ 本轮开始（《五行大义》《郭氏元经》）
· 命理逻辑依古籍，不依现代简化（巳申"合刑同时存在"）      ✓ 本轮
· 命例库 ＋ 出处（我们独有）                            ✓ 已有
· 依据分级四档（典籍／古法／民俗／产品设定）              ✓ 已有
· ★「并见时取哪一项」标明为【我们的规则】，不冒充古法      ✓ 本轮
```

**★ 这五条合起来，就是「比竞品更古籍」的真正路径**——
**不是靠放断语，而是靠依据更厚、出处更实、边界更清。**
